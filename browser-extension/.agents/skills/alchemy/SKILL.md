# Alchemy — 参考图逆向与风格重构

目标是把可见证据转成可执行的生成指令。不能从单张图恢复唯一的原始 prompt、模型或制作流程，也不能用裁切次数、像素读数或主观评分承诺“95% 相似”。

## 执行顺序

1. **定任务与归属。** 选择还原参考图、提炼可迁移风格、新主体重演模板、保留结构换画法或定点纠偏。标明实际输入顺序、各图职责和用户锁定项；单张图即可逆向，文字描述也可提供新主体。
2. **先完成 observation，再写词。** 必须读取并执行 [观察流程](references/workflow.md)：整图定位 → 工具裁切/放大 → 逐区辨别与必要测量 → 整图回看 → 观察验收。只看一次整图、只得到风格标签或只生成裁切文件，都不算完成。工具受限时按其中的降级规则交付。
3. **按需适配。** 对当前题材查 [场景适配](references/domain-adaptation.md)；新主体、模板效果重演或“只像滤镜”的纠偏读取 [模板重演](references/template-reconstruction.md)。只加载有关条目，不预设人脸、姿态或文字规则。
4. **证据转指令。** 按 [提示词结构](references/prompt-contract.md) 将重要观察落实到具体区域与关系；涉及人物身材时用直接体型词和部位形状、比例写明关键特征。删除冲突旧句，再压缩表达。最终篇幅短不代表可以缩减观察深度；批量任务逐图完成观察和适配。
5. **按请求交付。** 分析/逆向/写词默认只交付提示词；仅在用户要求出图时使用可用的 imagegen Skill，按 [结果校验](references/evaluation.md) 复核和有限修正。工具不可用时说明执行限制。

## 不变原则

- **用户明确取舍优先。** 内容、结构、画法分别分配来源；助手旧词不是用户硬约束。保留身份不自动锁死姿态、机位、衣着与背景，模板相似也不能覆盖用户锁定项。
- **先整体后局部，再回整体。** 主次、空间、比例、明暗面积决定整体；局部决定材料响应、笔触与边界。精细观察不等于放大所有对象，也不等于把微纹理写得更强。
- **风格由关系形成。** 写清谁覆盖谁、亮暗如何过渡、纹理在哪停止、配件如何建立焦点。承载效果的形状、遮挡与姿态可以是风格机制，不能只当可删除的物体清单。
- **观察与推测分开。** 不可辨的文字、微纹理、遮挡结构和物理材料不补造；字体、焦距、色号等精确值须有证据。不能观察到的细节不因高还原目标而变成事实。
