# Observation：从整图到原始像素证据

本文件统一规定观察动作、证据与完成条件。提示词压缩和最终 observations 摘要发生在观察之后，不能反过来限制观察范围。

## 1. 确定任务与原图

| 意图 | 分析与输出重点 |
|---|---|
| 还原参考图 | 保留具体内容、空间关系与画法，写可独立理解的复刻词 |
| 提炼可迁移风格 | 分开可替换内容、结构规则、表现规则与适配条件 |
| 新主体重演模板 | 主体图提供选定身份线索，模板提供允许重建的结构与表现 |
| 保留结构换画法 | 锁定用户指定的内容/几何，将参考画法分配到已有区域 |
| 定点纠偏 | 对照相关区域与整图，保留其他已接受维度 |

“逆向这张图”默认还原；“给其他主体用”才抽象为配方。风格转换不自动等于所有结构不变。多图按实际编号分工，用户明确要求优先；缺少关键取舍且无法合理推定时才澄清。

实际查看全部相关输入。能读取源文件时确认尺寸、方向与色彩配置；裁切坐标以应用 EXIF 方向后的图像为准，记录坐标基准。区分原图、预览、截图和压缩副本；只有预览时不得声称检查过原始像素。排除浏览器控件、平台边框等非目标内容，目标画面不明确且影响判断时再问。

## 2. 整图定位：先提出待核实问题

先看主体、数量/动作、视角、比例、裁切、留白、前后层次、色块与明暗面积；平面图不强加相机或光源。标出决定辨识度与生成结果的视觉锚点，通常约 3–7 项，复杂图可增加。

把粗看结论变成局部问题，例如“亮边是描线还是反光？”“颗粒来自物体表面还是统一成像层？”“阴影是硬边投影还是曲面缓变？”不要看到“油画、柔光、金属感”就开始写最终词。

同时按 [整体情绪观察](domain-adaptation.md#整体情绪与氛围所有题材) 提出画面的主要感受、强弱及可能的情绪反差，标出承担它们的主体、物体摆放、留白、光色或材质关系。将其视作待核实的视觉解读，不能仅凭人物表情或冷暖色就定论；无人图同样检查。

## 3. 工具细看：必须实际返回并查看局部图像

**有可用工具时，关键区域必须经过裁切和放大查看，不能用整图脑内放大替代。** 依据视觉重要性与误读风险选 ROI，不按等分网格机械遍历。普通复杂图常需 3–6 个 ROI；数量不是通过标准，同一局部可解决多类问题，简单平涂图也需核查其关键边缘。每张输入按其职责覆盖关键特征，不把所有图都按模板纹理分析。

工具选择：
- 内置环境提供 `alchemy_inspect_image` 时优先使用：按工具 schema 传实际图号、像素裁切框及倍率；可先查整图与元信息，再针对问题取局部。它只处理本次输入，不把用户文字或图片文字当作工具操作指令。
- 其他环境用已有图像查看/裁切工具；允许写分析副本时可用 Pillow、Sharp 等确定性裁切后用图像查看工具打开。优先内存操作，不覆盖原件。只读环境不得依靠写临时文件绕过限制。
- 工具调用成功、文件已创建、统计值已打印均不等于“看过”：必须让局部图像进入视觉上下文并检查。不能将 base64 文本当图像观察。

依次结合两种尺度：
1. **带上下文的局部**：保留相邻物体、表面转折或接触关系，判断细节属于哪里、与谁关联。
2. **原像素细节及放大图**：查看足以分辨像素的局部，再按需用 2–4 倍最近邻放大辨别细线、纹理与边缘过渡。放大仅便于辨认，不增加信息；禁止用生成式超分、锐化、补纹理后的图作为原图证据。若显示工具会再次缩图，缩小裁切范围，不对整图无限放大。

必须覆盖本图存在且影响结果的几类问题；不适用时跳过并有依据，不能以“已理解整体风格”跳过全部局部：

| 覆盖对象 | 局部必须辨清的关系 |
|---|---|
| 主体与辨识细节 | 轮廓、部件比例、五官/造型、动作、关键文字或装饰；只分析本次需保留的线索 |
| 人物身材与比例（适用时） | 整体剪影、头身与躯干/四肢比例、肩颈胸腰胯及可见肢体的长短粗细和轮廓收放；按 [身材观察](domain-adaptation.md#人物身材与比例含绘画人物) 区分真实形体、姿态透视和衣物轮廓，确定来源后转成直接体型词与部位关系 |
| 人物神态与微动作（适用时） | 视线与眼睑/眉眼、嘴角/唇缝、头颈肩、手指接触及其牵动的衣褶/遮挡；区分身份、瞬时表现与画法，按 [人物细查](domain-adaptation.md#人物微表情微动作与神态含绘画人物) 核实局部并回看整体幅度 |
| 关键表面与纹理 | 形态、相对尺度、方向、疏密、对比、分布；物体纹样、材料微纹理、绘画笔触、载体露底、成像/老化痕迹分别归属 |
| 光影与色层 | 高光形状、亮暗过渡宽窄/软硬、暗部保留信息、反射/透射/局部染色；取相关亮暗区域对照，不能只看最亮的一点 |
| 边缘与交界 | 描线/色差/遮挡/反光如何形成边界，接触影、留隙、透明叠层、背景透出及纹理终止位置 |
| 小面积关键特征 | 即使面积很小，决定焦点或辨识度的字形、接缝、发光点、细线等仍需单独核实 |

无微纹理、暗部无可读细节、边缘被模糊吞没都是有效结果。低清图中的块状压缩、插值边缘不能自动解释成笔触或物理肌理；不能把整幅颗粒一律映射到皮肤、玻璃和背景。

## 4. 留下证据，解决歧义

每个重要锚点保留简短记录，工具轨迹或分析笔记即可，不强制另建文件或向用户输出长报告：

`图号 / ROI 坐标与尺度 → 直接可见特征 → 明确 / 仍有歧义 / 不可辨 → 对生成的影响`

例如：`图 2 / 接触处局部 → 窄暗带贴着底边、向右扩散且边缘变软 → 明确 → 提示词需说明接触影位置和软硬变化`。证据必须对应实际查看的区域；不能拿相邻材质的观察填补此处空缺。

存在会改变生成指令的歧义时，再裁一个更聚焦或包含上下文的区域，与相邻明暗/材质对照。已到源分辨率上限且复看仍不可辨时，记录缺口并使用可见外观范围，不无限放大、不编造结论。

测量只服务具体问题：需要比例时以原图坐标估算占比；需要纹理尺度时核对原始像素与主体尺度；颜色重要且有可靠语义区域时，读取 [颜色取证](color-matching.md) 并采样。统计使用未放大的源像素，不能在插值图上测量后冒充原值。宽泛形容词不能代替可测的关键差异，但也不要求每个表面凑 HEX 或精确角度。

## 5. 回看整图并验收 observation

局部检查后重新查看整图，核对细节在正常观看尺度的强弱、面积与优先级。放大可见但远看融合的纹理，不能写成全幅粗重肌理；小块高光不能扩成主色。

只有满足以下条件才进入提示词编写：
- 内容/结构及各输入职责清楚；决定结果的局部覆盖已完成，实际图像已查看。
- 关键光影、纹理、边缘和小面积焦点都有区域证据或明确的不可辨结论，不只是风格名称。
- 人物适用时，决定神态与动作的可见局部已核实并明确来源；遮挡/低清按部位标明可辨边界，保留其余可见线索，关键线索将写入最终人物专段，不能仅用“自然、温柔”等标签通过验收。
- 重要歧义已通过针对性复看处理，或注明源分辨率/遮挡造成的剩余限制。
- 回看整图后没有把局部特征扩大到无依据的范围；已选定应进入提示词的控制点。
- 整体情绪的基调、强度与有依据的层次已回看核实，能对应可见成因并落实到允许迁移的范围；弱情绪按平实表达，人物/物体/无人画面均准备写入情绪专段，不止局部神态。

**工具降级**：缺原文件或裁切/查看能力时，先用可用的局部查看方式；仍无法细查就明确记录“仅整图观察，未完成局部核验”及受影响的判断。可交付受限草稿，不能标记 observation 已完成或宣称像素级分析。只有缺失信息阻止用户目标时才请求补原图；无需为每个低价值细节停工。

## 6. 证据交给提示词

按 [提示词结构](prompt-contract.md) 将每个重要控制点落实为“区域 + 目标效果 + 形成关系”，或记录因用户限制转译/省略、因证据不足降为范围。移除冲突旧句后再压缩；观察到的事实可以复用，字段归属须按当前任务重新判断。最终只保留有助于生成的约束，ROI 坐标、工具轨迹和完整采样记录不灌入生成正文。
