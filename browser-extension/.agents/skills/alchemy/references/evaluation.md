# 结果校验与有限纠偏

## 仅交付提示词

按 [Observation](workflow.md) 验收观察，再完成 [实际提示词检查](prompt-contract.md)。只写词到此结束，不能宣称图像已验收或触发生成。

## 生成后按同一证据复核

先看整图，再用工具裁切对应关键区域，回到整图判断差异的重要性。参考与结果分别定位相同语义部位，不能把相同坐标当配准。已有来源图时，用来源评用户保留项，用模板评迁移效果。

| 维度 | 主要检查 |
|---|---|
| 内容与结构 | 主体、数量、身份/几何、姿态、视角、比例、裁切、留白、遮挡与空间关系 |
| 人物身材与比例（适用时） | 按各角色的指定来源对照整体体量、头身/腿身关系及肩腰胯、四肢的长短粗细；检查提示词是否抽象化丢失关键体型，或误将透视/服装轮廓变成瘦身、拉腿与统一美化，区分新设计与已观察特征 |
| 整体情绪与氛围 | 按任务来源对照主要感受、强弱、次级情绪或反差及其视觉成因；覆盖人物和无人/物体画面，检查是否过度戏剧化、仅表情相似却氛围偏移，或为情绪擅改锁定结构 |
| 人物神态与微动作（适用时） | 按该路径指定的来源逐人核对视线目标、眉眼/唇角的幅度与不对称、头肩偏转、手指接触及衣褶牵动；保留局部遮挡下仍可辨的线索，防止微表情夸张、神态串用或补出被遮五官 |
| 色彩与光影 | 色层位置/面积、相邻对比、亮暗过渡、高光形态及接触影；必要测量见 [颜色取证](color-matching.md) |
| 表面与边缘 | 纹理形态/尺度/方向/强弱、载体与物体分层、光泽响应、透明叠层、纹理覆盖与终止 |
| 文字与精度 | 需要的文字、字形特征与排版；无可辨细节处是否被错误补纹理 |

记录最重要差异的“参考状态 → 结果状态 → 修改方向”，先修整体结构与光影，再修细纹。局部色值接近不代表整幅复刻通过；颜色和颗粒相近但视觉结构仍跟随原照，也不能判为模板重演成功。

人物换姿态另查头颈肩胸、骨盆与四肢的连接/承托、视线目标及衣领发丝遮挡；区别合理回头、刻意夸张与生硬拼接，遮挡处不能声称已验证。

## 有限修正与记录

针对影响最大的偏差，替换冲突句或补充区域关系，再复核其他保留项。已有生成授权时可做一次定点修正；用户另定迭代数量时遵循其范围，否则仍有问题就报告，不无限重抽、不自动改为后期调色。

记录实际提交词、输入顺序/职责、生成或编辑条件、结果与修正原因；使用当前环境允许的记录位置，不为记录绕过只读限制。工具未暴露的模型快照或 seed 不得声称相同。

提示词草稿、静态流程验证、带图生成、纯文生成、编辑结果是不同证据。只报告实际检查范围和残余问题；单次改善不能证明因果或随机稳定性，也不能把局部像素指标换算为整幅相似百分比。额外生成实验须属于用户授权的测试范围。
