# 从观察到可执行提示词

先通过 [Observation 验收](workflow.md)，再筛选和压缩；交付篇幅与分析深度分开。用户指定的语言、格式、原样提交要求优先，不固定生成平台参数。

## 统一骨架

除完整复刻按 [专节](#完整复刻开头定性与结构锚点) 的顺序组织外，按以下顺序组织，省略无关字段；短任务可合并自然段，整体情绪专段与适用的人物专段按下文独立保留：

1. **任务与输入职责**：还原、配方、重演、锁定结构或纠偏；各实际输入提供什么。
2. **内容与结构**：主体、数量、状态、文字、用户保留项；人物的具体体型与关键部位比例；视角、位置/比例、裁切、留白、前后层次。
3. **分区域表现**：颜色角色与覆盖、明暗过渡、高光形状、媒介、纹理的形态/尺度/方向/强弱。
4. **关键关系**：接触、遮挡、透明/反射、轮廓形成方式、表面和背景如何衔接。
5. **防错与规格**：仅列当前图容易发生的误解，以及用户需要的比例、文字、背景等。

内容与结构之后写整体情绪专段，再接适用的人物专段；后续分区域表现与这些情绪成因保持一致。完整复刻的写法见 [完整复刻](#完整复刻开头定性与结构锚点)。

每个重要观察都有去向：写成区域指令，因用户限制转译/省略，或因证据不足改为有依据的范围。不能用“严格参考原图、细腻质感、95%还原”替代控制点，也不把坐标、工具轨迹和完整测量报告塞进 prompt。

## 按模式分配内容

| 路径 | 应写入的内容 |
|---|---|
| 完整复刻 | 开头定性核心技法，再写画幅镜头、版式占比、主体结构与分区域表现，见下文“完整复刻”。写成独立文本，纯文生图不得依赖“如图”；另输出 [可编辑元素](#可编辑元素仅完整复刻) |
| 仅提取通用风格 | `[SUBJECT]` 等用户需要的变量，加稳定的空间/色彩/媒介关系与适配条件；不能锁死原物体清单，也不能泛化成风格标签 |
| 提取风格（双图） | 输入职责与迁移范围 → 锁定的内容、几何及空间关系 → 各已有区域的画法和交界；结构不变不自动锁定所有颜色/光照 |
| 主体重演、多图重演 | 实际输入职责 → 选定身份线索 → 模板构图/姿态 → 明暗与可见度 → 焦点载体 → 材料细节；按 [重演规则](template-reconstruction.md) 转译兼容性，多图逐图绑定职责 |
| 会话创作 | 参考图的画法职责 → 会话中已确定的内容、角色与场景 → 本次配图的具体画面；区分已确定设定与必要的创作补全 |
| 定点纠偏 | 偏差所在区域、目标表现与须保留项；替换冲突原句，不在末尾累加相反命令 |

多图编号与实际提交顺序一致，没有提交的图不能引用。专属提示词展开变量，不留下 `[SUBJECT]`。一个输入可承担多种职责，文字也可提供目标主体；不预设“图 1 永远是人物”。

## 技法定名：用生图模型认得的标准术语

生图模型对标准技法名的响应远强于自造描述。局部证据能确定具体媒介、成像或后期工艺时，必须用该领域的通行名称定名，再写形成机制与作用范围；中文提示词在中文名后括注英文原词，英文直接使用原词。例如：有序抖动（ordered dithering，Bayer 矩阵）、误差扩散抖动（error diffusion dithering）、半色调网点（halftone dots）、像素画（pixel art）、赛璐珞平涂（cel shading）、卡通渲染（toon shading）、低多边形（low-poly）、体素（voxel）、等距视角（isometric）、厚涂（impasto）、湿画法水彩（wet-on-wet watercolor）、水墨晕染（ink wash）、丝网印刷（screen print）、孔版印刷（risograph）、木刻/麻胶版（woodcut / linocut）、胶片颗粒（film grain）、CRT 扫描线（CRT scanlines）、色差（chromatic aberration）。

- **先辨别再定名**：相似工艺用局部像素区分。半色调是旋转网格上大小渐变的圆点；有序抖动是固定小矩阵重复的开/关像素图案，明暗靠图案密度；误差扩散是无规律的噪点分布；像素画看网格是否统一、边缘是否无插值。证据不足时写可见外观，不猜名称。
- **写清工艺链与参数**：多步工艺按顺序写，例如“3D 渲染（3D render）→ 降采样为约 160×120 的像素网格 → 双色有序抖动，硬边放大不插值”。调色板色数、像素网格分辨率、网点/线条疏密等有证据时给出近似数值。
- **名称加机制，不只贴标签**：术语后紧跟区域、尺度和关系，名称不能代替控制点。流派、艺术家、工作室等画风归属名称须有确凿依据才写；画面内容里可确认的角色、地标、作品与产品按 [专名](#专名可确认的已知角色地标作品与产品) 标明身份，与画风归属分开。

## 完整复刻：开头定性与结构锚点

完整复刻的提示词用于纯文生图，模型最看重开头。正文第一句直接写画面类型与核心技法（含上节标准术语），不写“还原参考图”“任务与输入职责”之类没有画面信息的句子。写实照片的技法即成片类型与景别，可与主体的类别先验合成首句，如“成人东亚女性高质感近景肖像，竖幅 9:16”。随后必须写出以下结构锚点，图中不适用的才省略：

1. **画幅与镜头**：横/竖/方画幅及近似宽高比；机位高低、俯仰角、镜头感（广角夸张/中焦自然/长焦压缩，或正交、等距、平面无透视）、透视类型与消失点大致位置。
2. **版式与占比**：主体在画面中的位置与近似占比（如“主体占画面高度约 70%，中心略偏左”），地平线或主要分界线的位置，裁切边界，留白所在区域。
3. **主体结构与外观**：主体朝向与姿态（按 [姿态与朝向](#姿态与朝向方向角度与可见后果) 分段写方向、角度与可见后果），关键部件的数量、形状和相对比例（头身比、四肢长短、部件大小关系），再按 [主体外观](#主体外观类别先验与部位短语) 写外层造型与识别部件，具名主体按 [专名](#专名可确认的已知角色地标作品与产品) 简写与原作一致的特征。这些是复刻的骨架，不能被风格描述挤掉。
4. **分区域表现**：按区域写色彩、明暗、笔触/纹理及其尺度，见下文写法；写实成像补上清晰度分布与色调主词。

完整复刻交付一篇连贯的画面描述，神态与整体情绪织入正文，不另起带标题的段落：

- **神态**：视线目标、头颈偏转与手部接触写进主体朝向与姿态句（“脸向画面右侧转约 15°，目光回到镜头”“头向画面左侧倾约 10°，右手指尖轻触下颌”）；眼睑、眉眼、唇缝与嘴角的状态写进识别部件的部位短语（“眼睑半垂”“饱满微张裸粉唇”）。证据、幅度与不对称仍按 [人物专段](#人物专段) 判断。
- **整体情绪**：光质、色调主词、留白与清晰度已写出情绪成因，正文结尾用一句收束主要感受与强弱（“整体干净、安静、克制”），再接成片类型定位。来源与强弱按 [整体情绪专段](#整体情绪专段) 判断，平实画面照实写平实。

## 可编辑元素（仅完整复刻）

完整复刻还要输出 `editProfile`，供用户在原图上点名修改后生图。它不是提示词的一部分，只描述“图里现在是什么”。原图编辑的生图提示词只由它和用户的修改拼成，复刻正文与 `negativePrompt` 都不发送：被修改的元素写成“图中为…，改为…”，其余元素按 `current` 原样列为保持项。所以 `current` 既是修改的定位，也是保持原貌的锚点。

- `styleZh` / `styleEn`：1–2 句画风锚点，写核心技法（标准术语）、媒介、配色倾向与笔触，使后续新增内容与原图同风格。
- `elements`：按可见内容扫描 3–10 个可以单独修改的元素，只列图中实际存在的项，按重要性排序。常见类别沿 [主体外观](#主体外观类别先验与部位短语) 的层次拆分：脸部特征（五官、脸型、肤色）、妆容、发型发色、表情、姿势与动作、服饰、手持物或道具、主要物体、背景场景、画面文字、主色调、光照与时段、天气。画面有人物时必列“脸部特征”与“姿势”，它们未被修改时承担身份与朝向的保持。脸部与妆容、脸部与姿势、主体与背景分开列；细小次要物体合并，不逐件罗列。
- 每个元素：`label` 为 2–8 字的中文名称（如“脸部特征”“姿势”“背景场景”“标题文字”）；`currentZh` / `currentEn` 用 1–2 句写清它在画面中的位置和当前样子，具体到编辑模型既能据此定位，也能据此保持原貌：外貌类元素用部位短语写当前样子（如“杏仁大眼，柔和平眉，细窄鼻梁，饱满微张裸粉唇”）；姿势类元素按 [姿态与朝向](#姿态与朝向方向角度与可见后果) 逐段写方向与近似角度（如“上身向画面右侧转约 20°，脸转回约 10° 看向镜头”），与正文姿态句一致。文字元素逐字写出可读文本并加引号，不可读则说明。只写事实，不写修改建议。

## 主体外观：类别先验与部位短语

主体外观决定“像不像”。所有路径都按下列层次由粗到细写，每层只写当前可见且影响辨识的项；完整复刻写在主体结构锚点内，其他路径写在内容与结构中。

1. **类别先验**：用一个短语先给出主体类别，让模型取到正确的默认外观，后面的部位短语再逐项修正。人物写年龄段与性别呈现，外貌人群特征明显时一并写（“成人东亚女性”）；动物写物种、品种与年龄段（“成年橘色短毛猫”）；物体写品类与主材质（“哑光陶瓷马克杯”）；绘画角色写角色类型与画风比例（“Q 版三头身少女角色”）。能确认的已知对象在类别先验之后补上 [专名](#专名可确认的已知角色地标作品与产品)，并按该节简写与原作一致的特征；其余只用可见外貌描述。
2. **外层造型**：服装、发型、毛色花纹、包装与配件，写成“颜色 + 类型/工艺 + 标志性细节”，如“黑色高领镂空针织上衣，前胸不规则弧形露肤剪裁”“黑发高盘发，发顶自然蓬松，脸侧两缕长碎发垂落”。小而关键的特征写明数量、长短和位置。
3. **识别部件**：每个部位一个短语，“形状/大小/颜色/状态 + 部位名”，逗号串联，如“小巧流畅脸型，杏仁大眼，柔和平眉，细窄鼻梁，饱满微张裸粉唇”。用该领域的行业词（美妆、发型、服装、宠物、产品工艺，见 [场景适配](domain-adaptation.md)）；部位写完后，可用一个模型熟知的风格总称收束（“韩系精致淡妆”），总称跟在部位之后。
4. **表面与真实感**：肤、毛、材质写颜色、通透或光泽、处理程度，并配上图中确有的真实痕迹，如“细腻精修但保留轻微真实纹理”“细碎飞发真实凌乱”。真实痕迹按证据写；光滑的插画或表面照实写光滑。
5. **光、清晰度与定位**：写光质与对比，并选一个**色调主词**贯穿背景、光和后期（“米灰奶油色纯净背景”“低对比奶油调”“轻微奶油滤镜感”）。写实成像写**清晰度分布**：焦点落在哪些部位，哪些边缘和区域柔化、如何过渡，背景虚化程度。最后用整体情绪加一两个模型熟知的成片类型定位审美（“介于高端证件照与韩系写真之间”），类型名有依据才写，放在具体控制点之后。

妆容、滤镜与质感的强度用“轻微、淡、略带、柔和”等词按证据校准，保持参考原有的幅度；几何偏转按 [姿态与朝向](#姿态与朝向方向角度与可见后果) 用角度写。

**多个主体**：每个主体以“画面位置 + 类别先验”起句（“左侧的成人女性”“右前方的橘猫”），它的外层造型与部件只写在本句；主体之间的距离、朝向、接触、遮挡与视线单独一句；光、色调主词、清晰度分布与定位只写一次，并写明焦点落在哪个主体。次要主体写类别先验加 1–2 个识别特征，篇幅留给主要主体。

外貌来源与 [身材来源](#人物身材直接体型词与局部形状) 按同一张路径表分配：完整复刻取参考图；提取风格（双图）取主体图；仅提取通用风格把具体外貌留给 `[SUBJECT]`，只写画风如何表现五官、发丝与材质；重演和多图按身份来源逐个绑定；会话创作取当前要求与会话中已确定的设定，参考图只供画法。外貌、身材与神态分层写，互不替代。中英文保持同一组部位与强度，英文用对应行业词，如 almond-shaped eyes, upturned black eyeliner, high bun with face-framing strands。

## 专名：可确认的已知角色、地标、作品与产品

最终画面需要出现的主体、物品或场景若是已知的虚构角色、吉祥物、地标建筑、艺术作品或产品型号，在它的类别先验之后写出专名。名称让模型取到原作外观，替代逐部位的身份描写；与原作一致的特征再逐部位细描，会与名称争夺控制，把对象拉离原作。

- **先识别**：按 [整图定位](workflow.md#2-整图定位先提出待核实问题) 对每个这类对象提出具体候选，只凭已有知识，不联网检索。
- **确认标准**：用候选设计中稳定的标志核对，两项以上吻合即确认。角色看发型轮廓与发色、瞳色与瞳孔样式、面部标记、标志性饰物与配色；地标看轮廓、结构与周边；产品看外形比例与标识。同人图与二创中服装、画风或姿态与原作不同不影响确认。想不出具体候选，或只有发色这类一项泛用特征吻合时，只写外观，名称不进入提示词、observations 或 uncertainties。
- **写法**：中文名后括注原名，角色加注出处作品，如“日向雏田（Hinata Hyuga，《火影忍者》）”“埃菲尔铁塔（Eiffel Tower）”；英文写原名与出处，如 Hinata Hyuga from *Naruto*。确认后在 observations 写一条身份依据：名称加吻合的标志。
- **与原作一致的简写**：脸型五官、发型发色、瞳色、肤色、体型，以及地标与产品的标准造型，凡与原作一致，在专名后用一个短语点出两三个最有辨识度的标志，如“深蓝黑色公主切长直发，浅紫色眼眸”，不再逐部位展开。本节对具名对象覆盖 [主体外观](#主体外观类别先验与部位短语) 与 [人物身材](#人物身材直接体型词与局部形状) 的逐部位要求。
- **按图照常写**：与原作不同之处（服装、饰品、发型变化、年龄与体型差异、配色）写具体样子，让图中证据覆盖名称自带的默认设定；神态（视线、眼睑与唇的状态）、[姿态与朝向](#姿态与朝向方向角度与可见后果)、构图、光色与画风照常写。
- **出处不代替画风**：出处作品只标明身份，画风、技法与渲染按 [技法定名](#技法定名用生图模型认得的标准术语) 和本图证据写；同人、写实化或换画风的图照实写它自己的画法。
- **真实人物只写外观**：真实人物（含公众人物）不凭外貌识别具名。凭脸认人涉及隐私，生图渠道也常拒绝真实人名。真人 cosplay 可写所扮角色名，不识别扮演者。
- **来源按路径**：具名对象取自按路径提供其内容的输入。完整复刻取参考图；提取风格（双图）与主体重演取主体图，模板中被替换的原主体不具名，保留进画面的模板场景或物品可具名；多图重演按每图职责；仅提取通用风格的 `[SUBJECT]` 不具名；会话创作的名称来自会话内容，不为参考图原主体具名；定点纠偏沿用原任务的来源。
- **editProfile 照常写全外观**：原图编辑附原图，身份由图 1 保持，`current` 仍按部位写当前样子，作为定位与保持锚点；写进专名会让编辑模型按名称的默认设定重画。

## 姿态与朝向：方向、角度与可见后果

所有路径中有主体时，按 [朝向取证](domain-adaptation.md#姿态与朝向所有主体) 的分段，把朝向写进最终正文的主体姿态句；完整复刻写在主体结构锚点内。

- **每段写三件事**：方向（以画面左/右为参照，必要时补“靠近镜头的一侧”）、档位与近似角度、一两个可见后果。如“上身向画面右侧转约 30°，画面左侧肩膀靠近镜头、显得更宽，另一侧肩膀被手臂遮住；脸转回约 15°，远侧耳朵仍露出，目光看向镜头；头向画面右侧倾约 15°”。英文写 “torso turned about 30° toward screen right, the screen-left shoulder nearest the camera and visibly wider, the far shoulder hidden behind the arm; face turned back about 15°, far ear still visible, eyes to camera; head tilted about 15° toward screen right”。
- **偏转写足**：偏离正面、端正、对称的状态写成主体的第一句姿态描述，用度数和可见后果承担几何偏转，“略、稍、微”只跟在度数旁说明程度。偏转是辨识关键时，在 `negativePrompt` 写出默认误读，如“双肩正对镜头，身体端正对称”。真正正对时同样写明“正对镜头，双肩平齐”。
- **视线、头与身体分开**：眼睛看向何处与头的朝向分写，头的转、倾、俯仰与躯干朝向分写。
- **镜头与主体分开**：机位的侧别与高低写在画幅与镜头里，主体自身的转动写在姿态句里。
- **来源**：与 [人物专段](#人物专段) 的动作来源相同，动物与物体同理；仅提取通用风格时，朝向承担构图机制才写成条件，不锁定参考主体的朝向。
- **多个主体**：每个主体的朝向写在自己的句子里，相互朝向（面对面、背对、同向、回头看向对方）在关系句里写一次。

## 人物身材：直接体型词与局部形状

涉及人物身材时，在内容与结构中先写最突出的体型锚点，再用部位、长短粗细和相邻轮廓关系展开，进入最终 `promptZh` 与 `promptEn` 正文。采用“直接体型词 + 具体形状”的写法，不把“身材好、比例优美、线条流畅、曲线玲珑”等抽象评价作为唯一描述，也不只放在 observations 或排除项中。显著特征可直接用“大长腿、细腰、宽肩厚背、粗壮、圆润、矮壮”等日常词，不必弱化成含混的审美术语。

下表是按证据选用的表达示例，不是整套套用的理想身材，也不是固定同义词替换；同一概括可能对应不同形状，只展开当前确实存在的特征：

| 观察到的特征 | 可直接用于生成的表达 |
|---|---|
| 腿部明显修长 | 大长腿，大腿和小腿都长，腿部占全身比例明显偏大；若只有小腿显长，就只强调小腿 |
| 高挑纤细 | 身形高而瘦，躯干窄、手臂细；头小、脖子长或腿长须分别有依据，不能由“高挑”一并推定 |
| 腰胯反差明显 | 细腰，腰侧明显向内收，胯部比腰宽，两侧从腰到胯向外展开 |
| 胸部轮廓鲜明 | 胸部丰满，胸前轮廓明显向前隆起；或胸部平坦，胸前起伏小。按实际轮廓选用，不由细腰或性别推定 |
| 臀部形状鲜明 | 臀部圆润饱满，侧面轮廓向后突出；或臀部窄小，腰胯过渡较直。正侧面分别核对，不由胯宽推定后凸程度 |
| 肩背宽厚 | 宽肩厚背，肩部横向展开，上身厚实；有依据时补上臂粗壮或腰部较窄 |
| 肌肉量明显 | 粗壮的上臂、饱满的肩部肌肉、大腿结实；按可见部位写肌肉体积与分界，不默认补腹肌 |
| 丰满或圆润 | 身形圆润，腰腹饱满、上臂有肉、大腿较粗；胸部或臀部的饱满程度仅按可见轮廓单独描述 |
| 矮壮或紧凑 | 矮壮敦实，躯干短而宽、四肢较短且粗；画面占比小不等于身材矮小 |
| 头身或末端比例鲜明 | 小头长身、长脖子窄肩，或大头短身、短胳膊短腿；细手腕、窄脚踝、长手指按可见特征选用 |

长、细、粗、厚、宽、圆润是不同维度：大长腿不自动等于细腿，丰满不自动等于大胸，瘦不自动等于长腿。重点特征可以用一个直接词和一条形状关系强化，不堆“极致、超长、完美”等词继续加码；保留参考已有的夸张幅度，也保留普通、粗短、不对称等特征。中英文保持同一部位与强度，例如“大长腿”可写为 “strikingly long legs, with long thighs and lower legs”，不能只译成 “elegant proportions”，也不能误译成粗大的腿。

身材来源按路径决定，用户明确取舍优先：

| 路径 | 身材来源与适配边界 |
|---|---|
| 完整复刻 | 直接展开参考人物的可见体型、轮廓与比例，纯文字即可执行，不依赖“身材同图” |
| 提取风格（双图） | 具体化主体图的身材与比例，保留其几何；参考图只提供画法，不因其长腿细腰而改变主体 |
| 仅提取通用风格 | 不替缺失的主体指定身材；若夸张比例确属画风机制，写为“人物适用且允许比例风格化时”的条件，说明具体拉长、缩短或简化方式，否则身材交由 `[SUBJECT]` 决定 |
| 主体重演 | 身份相关体型取主体图，姿态、透视和允许迁移的比例风格取模板；逐项确定归属，不能借“统一比例”擅自把粗壮主体改成纤瘦人物。冲突先遵从用户锁定项，再转译模板效果 |
| 多图重演 | 按每图职责与保留特征逐人绑定体型和角色；物品、服饰、场景图不自动提供穿戴者体型，不将多个人平均成同一种身材 |
| 会话创作 | 从当前创作要求与会话中已确定的角色设定具体化身材，遵守后续修订；唯一参考图只供画法，不导入其人物体型。未定身材不冒称已知，必要创作补全须与已确定设定区分 |

已具名角色与原作一致的体型按 [专名](#专名可确认的已知角色地标作品与产品) 简写，与原作不同的比例照上表写。只写目标画面中适用的可见部位。头像不补腿长，宽松衣料不等于身体粗壮，高腰服装不证明真实腿长；透视缩短、低机位拉长、鞋跟增高与人体比例分开描述。不要为了强调身材改变裁切、姿态、服装遮盖或露肤程度；需要从近景构建全身时，区分新设计与原图证据，不编造精确身高、围度、头身比。年龄和体型分别判断，不把成人比例套给儿童或非人角色。目标无人则省略这些描述，重要不可辨项记入 uncertainties。

## 整体情绪专段

所有逆向路径（含仅提取通用风格）都输出整体情绪，人物、物体或无人画面都要写，不因目标无人而省略。完整复刻按 [完整复刻](#完整复刻开头定性与结构锚点) 织入正文结尾；其他路径在最终 `promptZh` 与 `promptEn` 正文中用空行分出 **整体情绪与氛围 / Overall mood & atmosphere** 段落，与人物微表情专段分开。按 [整体情绪观察](domain-adaptation.md#整体情绪与氛围所有题材) 写明主要情绪、表达强弱、有依据的次级情绪/反差，以及承载它们的具体视觉关系。观察摘要可概括感受与依据，但不能代替生成正文；用户另定格式时仍保留这些内容。

将解读改写成可执行目标，例如“整体呈现克制的疏离感，以主体较小的画面占比、周围连续留白和冷硬侧光维持距离感”，仅在当前证据与任务范围支持时使用这些控制点。不只写“高级、治愈、有故事感”，也不以新增人物、道具、天气或事件解释情绪。表达平实的图仍写其低情绪强度及客观呈现方式；不要为凑段落强加戏剧性。

| 路径 | 情绪来源与迁移边界 |
|---|---|
| 完整复刻 | 参考图的整体感受与强弱，在正文结尾用一句收束；形成它的光色、留白与清晰度已在前文写出，纯文字即可执行 |
| 提取风格（双图） | 保留主体图的表情、动作、几何、构图和内容关系；只用参考图允许迁移的色光、笔触、边缘和表面画法表达可兼容的氛围。参考情绪依赖被锁定的结构时不强行照搬，在限制中说明；正文描述兼容后的目标情绪，不能同时要求相反感受 |
| 仅提取通用风格 | 抽象参考图稳定的情绪基调与形成机制及适用条件，主体保持变量，不锁定原人物、物体清单或虚构缺失主体 |
| 主体重演 | 模板提供整体情绪与允许重演的视觉关系，主体图提供身份；按用户锁定项适配表达强度与机制 |
| 多图重演 | 模板统摄整幅氛围，各输入按职责参与，保留有依据的角色差异与情绪反差；不把所有来源的情绪叠加，也不强迫所有角色同一表情 |
| 会话创作 | 情绪基调取当前要求与会话中已确定的情节；参考图的光色与画法在兼容时承载氛围，不以参考原图的情绪覆盖会话内容 |

用户指定的情绪目标及保留项优先于默认来源；先协调冲突，再写一个自洽的生成目标。中英文保持相同的情绪方向、强弱、层次与成因，不能把“略带不安”翻成强烈恐惧。局部微表情与整体氛围可以有反差，但须说明这种关系，不能用整体情绪覆盖已锁定的微动作或补造隐藏面部。

## 人物专段

最终画面包含人物且有相关可见证据时，除完整复刻（按 [完整复刻](#完整复刻开头定性与结构锚点) 织入姿态句与部位短语）外，在内容与整体姿态之后单独写一段 **人物神态与微动作**；中英文输出分别在 `promptZh` 与 `promptEn` 正文内保留对应段落，用空行隔开，英文可标为 **Expression & subtle gestures**。这段属于直接用于生成的提示词，不能只放进 observations、附注或排除项，也不能以“严格参考表情”代替实际描述。用户明确另定格式时遵从用户要求，仍保留相关控制点。

按 [人物细查](domain-adaptation.md#人物微表情微动作与神态含绘画人物) 的证据，将视线目标与眼睑/眉眼、嘴角/唇缝/下颌、头颈肩的微小偏转、手指与接触、动作引起的衣褶或遮挡连成自然段；写清部位、方向、幅度、松紧及相互关系，只展开当前可见且影响结果的项。神态词是这些线索共同形成的观感，不替代它们。保留细小不对称与克制幅度，不为了“生动”加深笑容、瞪大眼睛或强化动作。多人逐一绑定身份/画面位置与互动对象，避免串用表情。

专段的来源随任务分配：

| 路径 | 人物细节来源与写法 |
|---|---|
| 完整复刻 | 参考图的具体神态与动作，织入姿态句与部位短语；用脱离图片仍可执行的文字展开，不能写“同参考图” |
| 提取风格（双图） | 默认保留主体图的表情、视线与微动作；参考图只提供这些区域的画法，不以参考人物的神态覆盖主体 |
| 仅提取通用风格 | 有人物参考时写“人物适用时”的条件段，提炼眉眼、唇线、姿态张力等如何被画法表达；具体表情、动作与身份留给目标主体，不锁死参考人物，也不虚构缺失主体 |
| 主体重演 | 主体图提供身份，模板提供可迁移的神态、微表情与微动作；按新身份和视角重建，不粘贴源脸投影 |
| 多图重演 | 按每图职责分别确定人物身份，再映射模板中的角色、神态、动作与互动；物品/服饰图不提供人物表情，角色无法对应时说明限制 |
| 会话创作 | 神态与动作取当前要求与会话中已确定的角色设定；参考图只提供这些区域的画法，不导入参考人物的表情与动作；未确定的部分按创作需要补全，并与已确定设定区分 |

用户明确锁定或更改某项时覆盖对应默认来源，并删除冲突句。目标无人时省略人物段，不因模板有人而添加人物；动物/非人角色按其可见结构适配。面部按部位判断可辨性：保留能确认的眼睑、视线、嘴角等可见线索，仅省略被遮或低清不可辨的部位，不推断隐藏形态；整脸不可辨时才转写可见头肩、体态与遮挡。重要缺口放入 uncertainties，生成正文保留应有的遮挡与可见度。两种语言须保留相同的方向、幅度、接触及否定约束。

## 写具体，但不夸大

将控制点就近绑定区域与关系，例如：

```text
[区域]以[颜色/色层分布]建立[明暗过渡与高光形态]，
叠加[纹理形态、相对尺度、方向、强弱]，覆盖[范围]并在[边界]衔接。
```

仅填写当前图有依据且影响结果的部分。无可辨微纹理时写可见光滑度与光照响应，不补毛孔、裂纹或织纹。混合媒介分区，不能用一个全局颗粒词替代各表面的不同表现。

必要时加入经 [颜色取证](color-matching.md) 核验的 sRGB 代表色；色号仍需绑定作用区域与覆盖范围，不能替代红晕、渐变、透射或反光的分布。

姿态写支撑、各段朝向（见 [姿态与朝向](#姿态与朝向方向角度与可见后果)）、关键接触与视线目标；身份特征随新视角重新表现，不把源图头部投影直接接上模板身体。细节分析用于决定这些关系，不整段复制骨架清单。

精确可读文字逐字列出；不可读时说明缺失或保留用户需要的文本变量，不猜字或字体名。输出位图不能冒充精确矢量、字体或可编辑排版。

## 提交前只检查实际词

- 关键控制点及其区域、分布、关系是否还在？压缩掉重复形容词，不压掉区别相近材质/画法的证据。
- 能确定的技法是否用了标准术语（中文括注英文）并写出工艺链与近似参数？完整复刻是否以技法定性开头，并写了画幅、镜头透视、主体位置占比与结构比例？
- 锁定项是否来自用户？是否混入旧姿态、旧光照、全局纹理等互斥句？改原句，不依靠最后一句“优先”抵消。
- 描述尺度是否符合整图？局部细纹没有夸成全幅粗纹，小高光没有扩成大色块。
- 主体外观是否从类别先验写到外层造型与部位短语（具名主体按专名简写），用了行业词，并配上有依据的真实痕迹？写实成像是否写了清晰度分布和贯穿的色调主词？多个主体是否逐个绑定、共享层只写一次？
- 画面中的已知角色、地标、作品或产品是否已识别，按稳定标志确认后紧跟类别先验写出专名？与原作一致的特征是否已简写成一个短语，与原作不同之处、神态与朝向是否仍照图写？没有具体候选的猜测、真实人物的名字和 editProfile 里的专名是否已删去？
- 主体朝向是否逐段写了方向、近似角度与可见后果？侧身、转头、倾斜是否被“略、稍”写弱，或可能被生图模型拉回正面对称？
- 人物身材是否已从抽象评价转成直接体型词和具体部位关系，且写入中英文正文？是否串用来源、将长腿等同细腿、因服装/透视误判体型，或把所有人物统一美化？
- 人物神态（专段，或完整复刻的姿态句与部位短语）是否落入实际生成正文？来源、注视目标、微小幅度、接触与遮挡是否一致，是否只剩情绪标签或在翻译中丢失？
- 整体情绪（专段，或完整复刻的结尾收束句）是否覆盖当前题材并写清基调、强弱、层次与可见成因？是否误把局部表情等同整图情绪、给普通物体添加心理/五官，或为强化氛围越过结构锁定项？
- 防错是否有本图依据？参考图有描线、文字、硬影就不能套“无描线、无字、柔光”等通用禁词。
- 批量任务是否逐条适配了字段与区域？共享骨架不能代替逐图观察；每条脱离批次说明仍可使用。

默认先交付最终提示词，复杂任务附少量关键锚点与限制。若输出格式限定 observations 为 3–6 条，那是充分观察后的摘要；未写进摘要的关键细节仍须落实到提示词。中英文输出时保留同一组约束，不借翻译删除细节。
