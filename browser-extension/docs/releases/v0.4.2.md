# QC-Reframe v0.4.2 · 自定义图片顺序与动态图号

2026-10-07 · 参考图默认在前，指令与生图按所选图片顺序执行。

## 图片顺序与默认指令

- 所有模式的新输入默认将参考图设为图 1。选中已上传图片后，可用「图片前移 / 图片后移」调整顺序；工作台支持主体之间排序及跨参考图移动，轻量窗口支持双图排序，多图在工作台调整。排序不改变图片的参考图或主体角色，角色互换仍是独立操作。
- 图条编号、逆向提示词使用的图片编号与生图附件顺序保持一致。改序后需重新生成提示词，避免沿用旧编号；生图会校验当前图片顺序与绑定提示词的快照。完整复刻仍按完整提示词进行纯文本生图。
- 系统默认任务指令按实际顺序注入图号，排序或增删图片后同步更新。例如参考图在前时，主体重演指令使用「图 2（主体图）」和「图 1（参考图）」。完全匹配旧系统默认的固定图号文案也会适配。
- 用户自行编辑的指令，即使只改一个字，以及主动清空的内容，均保留原样；其中手写图号需自行核对。旧任务、提示词和生成结果的历史快照不回写、不迁移。旧记录缺少顺序字段时继续沿用原有顺序，不强制改为参考图在前。

## 排序操作与键盘修复

- 图片顺序随项目、模式及版本保存，重新打开后恢复；保存中禁止重复操作，失败时保留原顺序并允许重试。
- 轻量窗口改序后保留选中的图片，成功采用保存结果后恢复图条焦点。保存失败或切换项目后的迟到响应不会夺取当前焦点，也不会把界面切回旧项目。

## 工具库与 UIUX 验证

- 开发预览与诊断脚本集中到 `agent-tool/`，保留扩展目录的预览入口。工具统一说明输入、输出、副作用及验证范围，复用生产组件和规则。
- 新增 UIUX 规范目录、静态检查、宽窄屏与键盘行为场景、截图及 trace、隔离真实扩展验证，以及分层验证命令和 CI 工作流。
- 设计变更记录校验来源与场景映射，视觉基线提供候选、差异比较和显式审阅流程；自动测试通过不等于视觉基线已获人工确认。

## 升级方式与数据

从 v0.4.1 或更早版本升级，需要同步更新完整仓库中的本机服务与浏览器扩展。图片顺序涉及 bridge 的输入保存、逆向和生图，Chrome ZIP 不包含这些服务端改动，不能仅替换 ZIP。

1. 保存重要编辑，等待任务完成或主动取消后，在原 `browser-extension` 目录执行 `npm stop`；前台服务请在原终端停止。
2. 保留本地改动与 `.local/` 数据，将完整仓库更新到 `v0.4.2`，执行 `npm run setup`、`npm start`，核对 `npm run status` 为 `0.4.2`、`ready: true`。
3. 重新加载原扩展，刷新工作台和已打开网页，确认扩展版本为 `0.4.2`。使用 ZIP 时解压到原加载目录，不删除原扩展或清空浏览器数据。

已支持插件内重启的托管服务，可在源码更新和构建完成后通过「设置中心 → 本机连接」重启；该按钮不下载更新、不重载扩展。本版无新增浏览器权限，保留已有项目、提示词、生成图片、配对及配置，无需手工迁移或重新配对，不修改 Codex 全局配置。轻量端未提交草稿不承诺跨浏览器重启保留。详见[安装与升级指引](https://github.com/AIDiscovery007/qc-reframe/blob/v0.4.2/browser-extension/docs/INSTALL_WITH_CODEX.md)。
