# QC-Reframe v0.8.1 · Claude Code 逆向、插件指令与更干净的上下文

2026-11-28。

[← 更新日志](https://github.com/AIDiscovery007/qc-reframe/blob/v0.8.1/browser-extension/docs/releases/README.md) · [安装与升级](https://github.com/AIDiscovery007/qc-reframe/blob/v0.8.1/browser-extension/docs/INSTALL_WITH_CODEX.md) · [首页 / Home](https://github.com/AIDiscovery007/qc-reframe/blob/v0.8.1/README.zh-CN.md) · [GitHub Release](https://github.com/AIDiscovery007/qc-reframe/releases/tag/v0.8.1)

**In English:** Claude Code joins Codex and Pi as a reverse agent, and the extension now tells you which supported agent CLIs are already installed. New **Plugin instructions** (插件指令) work like Reframe's own AGENTS.md / CLAUDE.md: a built-in instruction written from the view of a reverse-prompt expert and senior designer helps the model use precise, professional wording, and you can replace it in Settings. Reverse and Codex image generation now send the model only what the task needs, not your project or global skills, MCP servers, plugins, hooks or shell environment. From v0.8.0, upgrade in **Settings** (设置中心) → **Local connection** (本机连接).

## Claude Code 逆向

- 「设置中心 › 插件模型」新增 Claude Code，与 Codex、Pi 并列，只用于逆向；生图渠道不变。
- 每次任务运行一个 `claude -p` 进程：不读取用户、项目或本地设置（因此没有 hooks 和 CLAUDE.md），内置工具全部关闭，只连接 Reframe 的看图取证与读取技能资料两个工具。工具不符或回复的模型与所选模型不一致时明确失败。
- 本机 Claude Code 的登录账号、凭据环境或可执行文件变化后，需要重新「验证并使用」。
- 「设置中心」可管理 Claude Code CLI。查找顺序为 `CLAUDE_BIN`、服务 PATH 中的 `claude`、官方安装器的 `~/.local/bin/claude`。只有官方安装器的版本可在插件内升级；npm、Homebrew、桌面应用等安装显示各自的更新方式。

## 检测本机已安装的 Agent CLI

- 还没选好模型或缺少 Codex 时，插件检查本机已安装哪些 Agent CLI，只读取是否安装、版本与来源，不联网。
- 所选 Agent 的 CLI 缺失而其他 Agent 已安装时，提示可用的 Agent 并打开 Agent 卡片；不会自动切换。旧服务不支持检测时不显示提示。

## 插件指令

- 「设置中心 › 插件指令」相当于 Reframe 自己的 AGENTS.md / CLAUDE.md，每次逆向都附加给模型。默认使用内置指令：以逆向生图专家和资深视觉设计师的角度，把图中可见的证据写成专业、具体、可执行的描述，并要求每个术语都有图中证据。
- 可以改成自己的指令，最多 16000 字符，保存在 `.local/config/plugin-instructions.md`（仅本人可读写）。保存与内置相同的文本即恢复默认，此后跟随内置指令更新；清空则不附加任何指令。
- 本次任务指令、Reframe 的输出格式与 Alchemy 技能优先于插件指令；插件指令不能扩大工具或读取范围，也不能改变图片范围与编号。适用于 Codex、Pi 与 Claude Code 的全部逆向路径，不用于生图。
- 单个任务与批次在受理时冻结当时的插件指令，之后的修改不影响已受理的任务。自定义文件无法读取时，逆向明确失败并保留该文件。

## 逆向与生图只带任务所需的上下文

- 逆向只发送 Reframe 任务说明、所选路径的 Alchemy 技能快照、插件指令、本次图片（按图号顺序）、用户任务指令，以及 Reframe 的两个工具。
- Codex 的逆向与内置生图都在每次新建、用完即删的私有空目录中运行，以 Reframe 的说明替换 Codex 自身的基础提示。不再读入仓库或项目的 AGENTS.md、用户技能、MCP 服务、插件、浏览器、hooks、shell 及其环境快照。这些设置只对本次线程生效，不改动 `~/.codex`。
- Codex 内置生图只发送 Reframe 生图规则、已确认的提示词与排除项、按受理顺序的图片和内置生图工具，不再附带 imagegen 技能。
- Claude Code 不再继承宿主 Claude Code 会话的身份、邮箱、会话与令牌等环境变量，只透传登录、模型提供方与证书相关设置。Pi 原本就只收到上述内容。
- 仍会到达模型、没有开关的部分：用户全局的 `~/.codex/AGENTS.md`（Reframe 不修改 Codex 全局配置），以及模型自带的代码模式工具（在只读沙箱中运行，所有 MCP 服务均已关闭）。
- Codex 逆向与内置生图需要 CLI 支持 `thread/start.baseInstructions`。较旧的 Codex CLI 会在设置中心的功能接口检查中显示不支持，升级 Codex CLI 即可。

## 升级方式与数据

**从 v0.8.0 一键安装升级：** 等任务结束，在「设置中心 › 本机连接」点「升级到 0.8.1」。完成后扩展自动重新加载，再刷新已打开的网页。

**从 v0.7.0 一键安装升级：** 再运行一次安装命令，然后在扩展管理页重新加载 QC-Reframe，并刷新已打开的网页。

**源码安装：** 保存编辑并等任务结束，更新完整仓库到 `v0.8.1`，运行 `npm run setup`、`npm start`，再重新加载扩展、刷新工作台和网页。macOS 上 `setup` 重新注册的启动器会带上 Claude Code 登录所需的 `USER`，以及 `CLAUDE_BIN`、`CLAUDE_CONFIG_DIR`。

本版不新增扩展权限，无需数据迁移。插件指令在你保存自定义内容之前直接使用内置版本，不创建文件。项目、提示词、图片、生图渠道与服务配置保存在 `.local/`，全部保留。不修改 Codex、Pi 或 Claude Code 的全局配置。
