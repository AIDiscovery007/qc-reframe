## 逆向 Agent 与 CLI 管理

- 在「插件模型」顶部选择 Codex 或 Pi，分别保存并验证模型与推理强度。会话创作的会话来源仍为 Codex；连续流程及批次分别冻结逆向与生图配置，后续切换不改写在途任务和历史。
- CLI 版本、实际路径、安装来源、检测与更新集中在「插件模型」，随顶部 Agent 卡片切换。旧 CLI 入口及恢复入口进入当前 Agent 管理区，需要其他 Agent 时由用户切换卡片。
- Pi 支持一键安装和已核实来源更新；支持原生自更新的版本使用原 CLI 更新本体，保留实际安装位置。受管安装先验证候选再切换，成功复检后回收有安装器标记的旧目录与本次缓存；失败或取消保留旧安装。
- 设置页简化重复入口与状态说明，验证成功仅对应当前配置，保留异常诊断、窄屏布局与键盘焦点。

## 自动连接本机服务

已批准的 Reframe 扩展自动连接正在运行的本机服务，无需手填配对码；Codex 与 Pi 共用连接，已有凭据保留。后台任务提醒也可自动续凭据，保留去重与失败后的定时重试。

标准 `.output/chrome-mv3` 目录直接识别；ZIP、移动目录或特殊加载路径需安装者核实并登记实际扩展 ID。普通网页和未知扩展不能获取凭据。扩展不能自行安装或启动本机服务，也不会代替用户登录或自动发起付费调用。

## 生图渠道独立设置

保留 Codex 内置生图，新增 OpenAI 兼容 Images API、Gemini 原生 API 与本机 Magpie。逆向模型与生图配置分开管理；内置 Codex 生图不再显示文字模型配置区。旧配置默认沿用 Codex，不自动迁移渠道或密钥。

OpenAI/Gemini 直连分别保存地址、模型与本机密钥。Magpie 使用本机网关地址及目录中的完整模型 ID，无需在 Reframe 填写供应商密钥；连接成功只证明目录可读取，保存设置不调用模型。生图渠道未就绪时阻止逆向并生图与批量完整复刻，仍可仅逆向。

### Magpie 附图、连续与批量生成

Magpie 支持纯文生图、按提示词版本图序附图、逆向后连续生图和批量完整复刻，每次请求一张图。附图能力取决于所选模型；缺少必要图片时不静默降级。批量完整复刻仍使用纯文字生图，参考图只用于逆向。

手动、连续与批量任务使用受理时的渠道、模型、输入与尺寸快照。失败不自动切换渠道或重新调用模型；取消、重启与后续表单修改不会启动额外流程。服务重启不自动重跑中断任务。

### 模型选择与尺寸适配

工作台目标尺寸旁可直接选择 Magpie 生图模型，保存后同步全局设置；失败保留原选择，在途任务与历史不随之改写。

已识别 GPT Image 模型提供对应尺寸预设，自定义尺寸按比例与面积调整到最近合法尺寸；已识别 Gemini 按网关支持的比例请求，像素由网关决定；未知模型使用网关默认。手动、连续与批量共用规则，无需额外的提交尺寸预览。记录保留用户请求、实际提交及最终图片尺寸，历史不重算，图片不裁剪或拉伸。原厂尺寸规则不代表中转服务已实测支持。

## 保存失败与恢复

模型已返回图片但本地保存失败时，可「重试保存」已有产物，不再次请求模型。独立恢复关联先于图片写盘保存；图片已写入但任务记录未保存时，重启后仍可恢复关联并重试。恢复先于图片回收，关联损坏时停止启动并保留数据。

**完全未写入磁盘的图片只在服务内存中，必须保持服务运行并先重试保存。** 不保证所有保存失败都能跨重启恢复，也不会用重新生图代替保存恢复。

## 升级方式与数据

1. 保存编辑，等待任务完成或主动取消。已有「重试保存」结果先完成保存，再停止旧服务；前台服务从原终端停止。
2. 保留本地改动与整个 `.local/` 数据目录，更新完整仓库到 `v0.5.0`，在 `browser-extension` 执行 `npm run setup`、`npm start`，核对 `npm run status` 的版本及就绪状态。Chrome ZIP 仅含浏览器端，不能替代本机服务与技能。
3. 重新加载原扩展，再刷新工作台和已打开网页。ZIP 解压到原加载目录；不删除原扩展、不清空浏览器数据。加载路径变化时按[安装指引](https://github.com/AIDiscovery007/qc-reframe/blob/v0.5.0/browser-extension/docs/INSTALL_WITH_CODEX.md#5-自动连接并打开)核对实际扩展 ID。
4. 在「插件模型」核对所选 Agent，再独立检查「生图渠道」。使用 Pi 的一键安装需 Node.js 22.19+ 和 npm，登录及模型验证仍需完成；模型验证会发送少量文字请求，安装成功不代表真实生图已通过。

已有项目、提示词、图片、配置与连接凭据保留，不修改 Codex/Pi 全局默认模型。相较 v0.4.4 无新增浏览器权限；更早版本升级时按浏览器要求确认既有权限。具体操作见[安装与排错](https://github.com/AIDiscovery007/qc-reframe/blob/v0.5.0/browser-extension/docs/INSTALL_WITH_CODEX.md)。
