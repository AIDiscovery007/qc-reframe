# QC-Reframe v0.3.2 · 工作台入口复用与项目选择记忆

2026-10-04 · 在已有工作台继续创作，各项目记住自己的路径和版本。

## 所有入口共用一个工作台

- 网页图片菜单、快捷面板、任务提示、桌面通知与模型设置入口统一复用已有工作台并激活所在窗口，仅没有工作台时新建标签。连续点击不同入口共用串行队列，避免重复创建。
- 已有工作台在页内打开对应项目、提示词或图片版本，不重载页面；快捷面板接续当前草稿，保留其他项目未提交内容。任务数量按钮直达任务中心，模型与设置入口直达设置中心。
- 初始化与参考图读取期间到达的跳转仍能正确处理，过期响应不会覆盖较新的目标。

## 每个项目独立记住路径与版本

- 各项目记住上次选择的逆向路径，各路径记住上次选择的提示词版本；来回切换、刷新或重新打开工作台后恢复各自选择。
- 从网页直接打开工作台时优先恢复该项目记忆，新项目使用默认路径；不会继承另一项目的全局选择。
- 旧快捷草稿让位于后来保存的项目选择；明确打开任务、画廊作品或交接当前快捷面板时，仍定位当次指定路径和版本。其他项目记忆与草稿保留。

## 升级方式与数据

从 v0.3.1 升级无需重启 bridge、迁移用户数据或重新配对，无新增浏览器权限。本版仅新增保存在扩展本地的项目视图偏好，不改历史项目、提示词、图片或 Codex 全局配置。

1. 保存重要编辑，把 v0.3.2 Chrome ZIP 解压到原扩展加载目录；从源码使用时，保留本地改动与 `.local/` 数据，将完整仓库更新至 `v0.3.2`，在 `browser-extension` 执行 `npm run setup`。
2. 重新加载原扩展，再刷新工作台和已打开网页，核对扩展管理页为 `0.3.2`。仅更新文件或构建不等于实际扩展已重载。
3. 已运行的 v0.3.1 bridge 可继续服务，健康检查仍显示 `0.3.1` 属正常情况。完整仓库更新后若再次执行 `npm start`，管理脚本会拒绝复用版本号不同的服务；届时在任务结束后执行 `npm stop`、`npm start`，无需为本次界面修复立即重启。

Chrome ZIP 只含浏览器端，不含 bridge 与运行 skill；首次安装仍需完整仓库。从 v0.3.0 或更早版本升级，先满足 [v0.3.1 的服务端升级要求](https://github.com/AIDiscovery007/qc-reframe/blob/v0.3.1/browser-extension/docs/releases/v0.3.1.md#升级方式与数据)。轻量端未提交草稿属于浏览器会话数据，不承诺跨浏览器重启保留，重要编辑请先保存。详见[安装与升级指引](https://github.com/AIDiscovery007/qc-reframe/blob/v0.3.2/browser-extension/docs/INSTALL_WITH_CODEX.md)。
