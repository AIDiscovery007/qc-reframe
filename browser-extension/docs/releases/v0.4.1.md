# QC-Reframe v0.4.1 · 共用操作栏、风格自动判定与状态修复

2026-10-07 · 生成操作直接可见，项目与任务状态更稳。

## 工作台操作

- 生成提示词、目标尺寸与生成图片集中到主界面共用操作栏。两个生成按钮通过文案和状态区分，尺寸与生图无需先打开提示词，窄屏切换到结果视图后仍可操作。
- 提示词完成后不再自动展开，查看与编辑由用户按需打开；展开或放大面板时仍保留主操作入口及输入、编辑、运行保护。
- 指令放大与收起改为输入框右上角图标，保留可访问名称、键盘操作及收起后的焦点恢复。自定义尺寸在窄屏下完整显示。
- 移除画布重复模式文字、底部先后步骤说明和单独的「仅提取风格」按钮，保留必要进度、错误和禁用反馈。

## 风格自动判定与失败恢复

- 在「提取风格」模式点击生成提示词时，系统按当前有效主体判断：未上传主体，仅提取参考图的可迁移通用风格；有主体，结合主体输出专属提示词。当前任务指令均保留，其他模式行为不变。
- 通用风格仍须补充主体并生成专属提示词后才能生图，不将未指定主体的配方直接交给生图任务。
- 主体读取、保存中或资源损坏时阻止提交，不误判为未上传而降级；上传或保存失败保留原输入，允许重新上传、明确删除或切换上下文恢复。迟到失败不会污染新项目或新版本。

## 创作与任务状态维护

- 集中维护项目、模式、提示词版本与草稿的选择和失效规则，保存响应按上下文及导航轮次检查，旧响应不覆盖当前输入；服务端已完成的保存仍可在重新读取时恢复。
- 工作台与轻量结果共用生图资格判断、提交、取消、失败和图片读取逻辑。切换项目或版本后，旧请求仍更新原任务记录，但不会清除新视图的历史图片定位；离开再返回也不会接收旧视图动作。
- 逆向与生图共用任务执行和取消管理，每项任务保留独立取消信号；任务记录按冻结快照串行保存，成功落盘后才对外发布。中断任务在重启时先保存失败状态，再恢复任务列表，保存失败不冒充成功。
- 操作来源与通信规则集中维护，保留权限校验、旧页面消息兼容及现有数据格式。本轮不更换数据库或拆分服务，不改变五种创作模式的产品语义。

## 升级方式与数据

从 v0.4.0 或更早版本升级，需要同步更新完整仓库中的本机服务和浏览器扩展；仅替换 Chrome ZIP 不包含任务执行与保存改进。本版无新增浏览器权限。已有项目、提示词、生成图片、配对与配置保留，无需手工迁移或重新配对，不修改 Codex 全局配置。

1. 保存重要编辑，等待任务完成或主动取消后，在原 `browser-extension` 目录执行 `npm stop`；前台服务请在原终端停止。
2. 保留本地改动与 `.local/` 数据，将完整仓库更新到 `v0.4.1`，执行 `npm run setup`、`npm start`，核对 `npm run status` 为 `0.4.1`、`ready: true`。
3. 重新加载原扩展，刷新工作台和已打开网页，确认扩展版本为 `0.4.1`。使用 ZIP 时解压到原加载目录，不删除原扩展或清空浏览器数据。

已支持插件内重启的托管服务，可在源码更新和构建完成后通过「设置中心 → 本机连接」重启；该按钮不下载更新、不重载扩展。轻量端未提交草稿不承诺跨浏览器重启保留。详见[安装与升级指引](https://github.com/AIDiscovery007/qc-reframe/blob/v0.4.1/browser-extension/docs/INSTALL_WITH_CODEX.md)。
