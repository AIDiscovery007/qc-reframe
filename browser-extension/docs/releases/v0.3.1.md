# QC-Reframe v0.3.1 · 紧凑布局、推理强度与提醒跳转

2026-10-04 · 固定常用控件，按模型选择推理强度，从提醒回到已有工作台。

## 界面更紧凑，滚动时保留操作入口

- 「全部项目」的「全部 / 待逆向」与卡片、列表、批量管理合并到同一工具栏，窄屏自然换行。页头和工具栏固定，项目内容独立滚动。
- 画廊、全部项目与详情页共享 64px 页头，保留短窗口布局；画廊统计与筛选标签之间增加 12px 留白。

## 按模型选择推理强度

- 设置中心「插件模型」根据当前模型动态列出可用推理档位，标注推荐值；模型与档位一起验证，成功后保存并显示当前生效档位。
- 档位验证失败保留原有效配置与错误诊断，不再误判为模型权限失效；真正的模型访问拒绝仍按原规则处理。任务或验证期间禁止切换，不支持的档位由服务端拒绝。
- 兼容旧配置，新任务记录保存当次强度；不修改全局 Codex 模型或推理配置。

## 提醒回到已有工作台

- 单条、聚合和桌面提醒优先复用已有工作台并激活所在窗口，在页面内定位提示词、图片或任务中心；没有工作台时才新建标签，连续点击不会重复创建。
- 页内跳转保留具体版本并丢弃过期响应。修复接续草稿或读取参考图期间收到提醒却丢失目标的问题：初始化完成后处理最新提醒，同时保留草稿。

## 开发资料整理

本地原型、素材及验证证据集中到 `browser-extension/prototypes/`，保持 Git 忽略并排除正式类型检查；历史原型提交保留。正式构建不依赖这些本地资料，用户项目与图片不受影响。

## 升级方式与数据

从 v0.3.0 升级无需数据迁移或重新配对，历史项目、提示词、图片和插件配置保留，相较 v0.3.0 无新增浏览器权限。

1. 保存重要编辑，等待运行中的任务结束或主动取消，在原安装的 `browser-extension` 目录执行 `npm stop`。
2. 保留本地改动与 `.local/` 数据，将完整仓库更新到 `v0.3.1`，执行 `npm run setup`、`npm start`。本版推理强度及错误分类改动需要重启 bridge；不要停止仍在执行任务的服务。
3. 重新加载原扩展，再刷新工作台和已打开网页；核对健康检查与扩展管理页版本均为 `0.3.1`。仅更新文件或构建并不代表实际扩展已重载。

提醒跳转修复本身只改扩展，但本版整体包含 bridge 更新，仍须按上述步骤升级。轻量端未提交草稿属于浏览器会话数据，不承诺跨浏览器重启保留。

Chrome ZIP 只含浏览器端，不含本机 bridge 和运行 skill；首次安装及本次服务端升级均需要完整仓库。详见[安装与升级指引](https://github.com/AIDiscovery007/qc-reframe/blob/v0.3.1/browser-extension/docs/INSTALL_WITH_CODEX.md)。
