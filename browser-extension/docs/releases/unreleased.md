# 待发布

已发布的 v0.3.3 记录见 [v0.3.3 版本说明](v0.3.3.md)。以下为本地工作区待发布改动，未提升版本号、未发布。

## 会话创作

- 沿用现有工作台布局，在逆向模式中新增“会话创作”。一张参考图搭配弹窗勾选的完整 Codex 会话，支持标题搜索、分页与归档会话，最多选择5个会话，不选择单个 turn。已选会话始终独立置顶，可直接取消勾选；搜索、分页与归档切换不隐藏选择，候选列表独立滚动。
- 本机服务通过同一 CODEX_HOME 的 Codex app-server 读取所选会话，以用户文本和助手最终回复构造私有任务快照，再结合参考图风格生成提示词，沿用现有生图与结果展示。附件仅计数，不读取内容；完整正文不经前端接口传递。
- 改变会话选择会使当前提示词失效，历史版本保留当时来源；重做会读取新快照。读取失败、更新冲突或超限明确报错，不静默截断。
- 会话读取与提交使用可断开的扩展连接，关闭弹窗或更换搜索会取消旧读取；慢请求不会被旧35秒界面计时器提前判失败。读取阶段取消或超时禁止迟到写入；提交后丢失响应则提示重新检查项目或任务状态，不声称已回滚。

## 会话搜索

- 标题搜索复用专用只读 Codex 连接，采用 15 秒有界缓存；保留防抖、取消与分页。
- 在现有会话弹窗切换「标题和正文」，显式建立本地索引后按中文单字/双字、英文片段或多个关键词检索，显示短命中原文。选择仍是整个会话，最多 5 个，已选区及工作台布局保持原样。
- 索引仅读取用户文本和助手最终回答，不调用模型；独立 Worker 处理 SQLite 倒排索引，兼容 Node 22.15。支持进度、部分失败、增量同步、每日正文核对以及停止并清除；数据库损坏或 Worker 故障时仍能清除后重建，源会话和创作快照不受清除影响。
- 当前为词面检索，尚无语义向量搜索；首次建立速度取决于本机会话数量和长度。正文片段仅向可信扩展页面返回，完整内容继续留在本机。

## 人物身材描述

- 五条逆向路径（含仅提取通用风格）统一强化身材用词：直接体型词配合部位长短、粗细、轮廓与比例关系，覆盖大长腿、细腰、宽肩厚背、圆润、矮壮等特征，中英文保留同等强度。
- 身材按输入职责与用户设定归属；区分身份体型、比例风格及服装/透视效果，不默认瘦身拉腿或补造不可见身体。会话创作不从风格图导入人物体型。
- 规则用于新逆向与重新逆向，已有提示词和人工编辑内容保持原样。此项需在本机服务更新后重新逆向；尚未进行真实模型逆向或生图效果验证。

## 验证与本地使用

- 本机 Codex CLI 0.160.0 已验证 paginated 会话全文分页与生产读取适配器；其他版本接口不兼容时明确失败，不以摘要替代全文。
- 生产构建、类型检查及自动回归测试通过；工作台流程使用明确标注的示例后端核验。真实模型逆向和生图尚未验证。
- 会话搜索本轮完成本地实现与构建，尚未重启正在运行的 bridge；使用新搜索需更新本机服务。加载新构建需要在浏览器扩展管理页重载 Reframe，并刷新已打开的工作台或网页。实际扩展重载受当前工具协议限制，尚未执行，不等同于已安装扩展的实机验收。
