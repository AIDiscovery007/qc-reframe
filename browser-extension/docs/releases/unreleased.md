# 待发布

截至 v0.3.2 的阶段改动已整理至 [v0.3.2 版本说明](v0.3.2.md)。

## 任务提示音

- 提供 10 种 akx/Notifications 提示音：静谧、云朵、和弦、轻笛、微光、轻叩、琴弦、星点、双拍、轻讯。默认静谧，声音仍默认关闭；原音量、试听、合并与静默规则延续。
- 原始 OGG 随扩展打包，约 306 KiB；按作者 CC0 选项使用，保留[音源出处与校验](../../public/sounds/akx/SOURCES.md)。仅在播放时对较响音源做衰减，不改写原文件。
- 旧轻柔/清铃自动对应静谧/微光，保留开关与音量；更新后重新加载扩展、刷新已打开页面即可使用，不需重启本机服务。

## 项目输入原位保存

- 修复参考图旋转、互换、替换在工作台和快捷面板创建其他项目的问题，编辑始终保留原项目 ID；重复收集原图恢复最新输入。
- 主体图片与多图编排在编辑成功后按路径保存，失败保留原输入。单独编辑任务指令仍是草稿，随图片保存或任务提交落盘；提示词编辑仍需显式保存。
- 历史版本、画廊、任务中心、提醒与快捷交接恢复对应输入；历史和在途任务图片保持不可变。加入跨窗口输入版本校验，修复重启恢复与图片回收中的身份和引用风险。
- 不自动归并已有重复项目。更新需在任务结束后重启本机服务，重新加载扩展并刷新已打开页面。
