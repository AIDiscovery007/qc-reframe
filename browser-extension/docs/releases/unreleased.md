# 待发布

已发布的 v0.3.3 记录见 [v0.3.3 版本说明](v0.3.3.md)。以下为本地工作区待发布改动，未提升版本号、未发布。

## 新用户初始化与 Codex 兼容性

- `setup` 在 CLI 缺失、未登录或缺少 app-server 时允许先完成 Reframe 构建，提供后续安装、登录和设置中心检查指引；Node.js 与 Alchemy skill 的必需检查不放宽，`doctor` 继续严格检查 CLI。登录和版本复查命令使用实际检测路径并安全引用，不替换已配置的 `CODEX_BIN`。
- 沿用现有「Codex 与更新」，分开显示版本更新与功能接口兼容性。本机只读读取 CLI 接口描述，不调用模型；检查结果未知时提示但不拦截，明确不支持时只限制依赖该接口的功能。是否最新不等于是否兼容，不将某个开发机版本作为统一最低版本。
- 升级后清除旧模型验证，完成版本与接口复查后提示用户重新「验证并使用」，再显式重试原操作；不自动调用模型或重新提交失败任务。文本验证不证明内置生图工具、账号权限或额度可用。
- 保留项目、图片、配对和已有草稿；沿用原安装渠道处理 CLI，不用另一份安装掩盖路径问题。文档区分 CLI 更新、Reframe 源码与服务更新、扩展重载及网页刷新，使用手册的当前发布版本入口统一为 v0.3.3。
- 初始化回归以临时假 CLI、假 npm 验证缺失、未登录、旧接口及数据保留；本轮没有实际升级用户 CLI，也未完成真实旧版 CLI 兼容矩阵或模型逆向、生图验证。以上行为仍待发布，不包含在已有 v0.3.3 安装包中。

## 会话创作

- 沿用现有工作台布局，在逆向模式中新增“会话创作”。一张参考图搭配弹窗勾选的完整 Codex 会话，支持标题搜索、分页与归档会话，最多选择5个会话，不选择单个 turn。已选会话始终独立置顶，可直接取消勾选；搜索、分页与归档切换不隐藏选择，候选列表独立滚动。
- 本机服务通过同一 CODEX_HOME 的 Codex app-server 读取所选会话，以用户文本和助手最终回复构造私有任务快照，再结合参考图风格生成提示词，沿用现有生图与结果展示。附件仅计数，不读取内容；完整正文不经前端接口传递。
- 改变会话选择会使当前提示词失效，历史版本保留当时来源；重做会读取新快照。读取失败、更新冲突或超限明确报错，不静默截断。
- 会话读取与提交使用可断开的扩展连接，关闭弹窗或更换搜索会取消旧读取；慢请求不会被旧35秒界面计时器提前判失败。读取阶段取消或超时禁止迟到写入；提交后丢失响应则提示重新检查项目或任务状态，不声称已回滚。

## 会话搜索

- 标题搜索复用专用只读 Codex 连接，采用 15 秒有界缓存；保留防抖、取消与分页。
- 在现有会话弹窗切换「标题和正文」，显式建立本地索引后按中文单字/双字、英文片段或多个关键词检索，显示短命中原文。选择仍是整个会话，最多 5 个，已选区及工作台布局保持原样。
- 索引仅读取用户文本和助手最终回答，不调用模型；独立 Worker 处理 SQLite 倒排索引，兼容 Node 22.15。支持进度、部分失败、增量同步、每日正文核对以及停止并清除；数据库损坏或 Worker 故障时仍能清除后重建，源会话和创作快照不受清除影响。
- 当前为词面检索，尚无语义向量搜索；首次建立速度取决于本机会话数量和长度。正文片段仅向可信扩展页面返回，完整内容继续留在本机。
- 修复索引把工具日志等原始 RPC 数据累计计入正文读取预算导致的误报；分页响应过大时减少每页 turn 数，从原游标重试，不截断正文。保留单响应、正文、页数、时间和索引容量边界。
- 索引状态卡显示实际处理进度、可搜索数量及分类原因，部分未收录与整体不可用分开呈现；建立期间自动补充初次空结果。已选区和底部操作固定，有限高度下内容仍可滚动操作。
- 精简索引辅助文案；搜索范围复用公共下拉组件，工作台版本与紧凑面板的下拉箭头统一右侧留白。
- 索引完成后自动收起，保留覆盖数量和手动展开入口；复用现有折叠动效，重新建立及错误时展开，自动收起时保护键盘焦点。
- 复用现有技术栈和动态效果偏好新增任务编排组件：状态过渡240ms、完成勾选280ms。显式 localhost 模拟导出页使用1.2秒任务驱动进度，支持取消、重播、键盘即时反馈及减少动态效果；隐藏或卸载时清理模拟任务，真实索引进度不使用模拟值。

## 人物身材描述

- 五条逆向路径（含仅提取通用风格）统一强化身材用词：直接体型词配合部位长短、粗细、轮廓与比例关系，覆盖大长腿、细腰、宽肩厚背、圆润、矮壮等特征，中英文保留同等强度。
- 身材按输入职责与用户设定归属；区分身份体型、比例风格及服装/透视效果，不默认瘦身拉腿或补造不可见身体。会话创作不从风格图导入人物体型。
- 规则用于新逆向与重新逆向，已有提示词和人工编辑内容保持原样。此项需在本机服务更新后重新逆向；尚未进行真实模型逆向或生图效果验证。
