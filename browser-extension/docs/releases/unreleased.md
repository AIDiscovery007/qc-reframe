# 待发布

本轮已交付内容整理至 [v0.4.4 版本说明](v0.4.4.md)，正式发布验证与结果以该版本说明和发布记录为准。本文件仅记录后续尚未发布的改动。

## 新增与改进

- 已批准的 Reframe 扩展自动连接本机服务，Codex/Pi 共用连接，保留旧凭据；断开后自动重试，不再需要粘贴配对码。普通网页和未知扩展不能获得凭据。
- 删除工作台及轻量端的配对表单、启动说明，以及本机连接里的服务地址和重复 Codex 安装信息；CLI 状态集中在「插件模型」，保留服务重启入口。

- 逆向支持 Codex / Pi，设置以卡片切换，分别保存和验证模型。会话读取仍使用 Codex，连续流程和批次分别冻结配置。

- 设置新增「生图渠道」，支持 Codex 内置、OpenAI 兼容 Images API 与 Gemini 原生 API，分别保存地址、模型和本机密钥。手动、连续和批量生图使用受理时的配置；失败不自动切换或重试。

- CLI 检测、更新和安装说明归入「插件模型」，随管理目标显示 Codex / Pi；Pi 支持一键安装及受支持来源更新。移除 Pi 下重复的 Codex 生图模型，生图统一在「生图渠道」管理。旧 CLI 入口仍可定位正确管理目标，不改变已保存 Agent 或渠道。
- Pi 支持通过已核实的原生 self-update 命令一键升级 CLI 本体，保留实际安装位置；更新完成后复检并要求重新验证模型。
- 插件模型页按逆向 Agent、模型配置和本机管理整理层级，集中展示 CLI 版本、操作与错误；窄屏使用顶部分类导航，改善模型表单、长路径和键盘焦点。

## 修复

- 生图渠道未就绪时禁用逆向并生图和批量完整复刻，保留仅逆向；兼容未提供生图状态的旧服务。

## 升级影响

- 自动连接需要同时更新扩展和本机服务；标准输出目录直接识别，ZIP 或其他目录需安装者登记扩展 ID。不能由扩展启动尚未安装/运行的本机服务，不会自动安装、登录或付费调用 Agent。

- 需要同步本机服务和扩展；旧配置默认 Codex。使用 Pi 前安装并配置登录（设置中的一键安装要求 Node.js 22.19+ 和 npm），在设置中刷新并验证模型。自定义路径可通过 `PI_BIN` 配置。

## 验证与限制

- Pi 接入基于本机 0.84.2 协议，验证使用隔离 stub 与合成图片；未调用真实模型，真实视觉识别与供应商权限仍需使用时验证。
- Pi 认证文件变化会要求刷新并重新验证，包含 Pi 自身的 OAuth 自动轮换；不会静默继承可能属于另一账号的验证状态。
- API 接入使用合成图片和隔离 HTTP fixtures 验证；未调用真实供应商。自定义网关的模型权限、附图和尺寸支持以实际接口为准。更新后须重启本机服务、重载扩展并刷新工作台；旧配置继续使用 Codex。

- CLI 安装更新以隔离目录和进程 stub 验证；未安装或升级用户现用 CLI，未重启现用服务或重新加载扩展。
