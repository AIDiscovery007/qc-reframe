# 待发布

本轮内容已归入 [v0.8.1 版本说明](v0.8.1.md)，包含 Claude Code 逆向、本机 Agent CLI 检测、可自定义的插件指令，以及逆向与生图只带任务所需的上下文。验证结果与已知限制见该版本说明。

本文件仅记录 v0.8.1 之后的新改动。

## 完整复刻：更准确的复刻提示词与原图编辑

- **复刻提示词更易被生图模型执行**：逆向技能要求首句用标准技法/媒介术语定性，例如厚涂（impasto）、赛璐璐（cel shading）、半调网点（halftone），多步工艺写清顺序；随后写画幅、机位、主体位置占比和关键结构比例，再分区域写色彩、明暗和笔触尺度。不再写「还原参考图」这类无画面信息的句子。
- **复刻提示词是一篇连贯描述**：神态写进姿态句与五官短语，例如「正面直视镜头」「饱满微张裸粉唇」；整体情绪在结尾用一句收束，例如「整体干净、安静、克制」。不再分出「人物神态与微动作」「整体情绪与氛围」两个带标题的段落。其他路径不变。
- **自动尺寸跟随参考图**：完整复刻选择「自动」时，按参考图宽高比追加比例约束；Codex 内置渠道通过提示词约束，OpenAI/Gemini 直连还按该比例请求尺寸。Magpie 仍使用网关默认尺寸。
- **原图编辑**：工作台的完整复刻新增「生图方式：文生图 / 原图编辑」。逆向时 Agent 会扫描图中可编辑元素，例如五官、姿势、背景、文字；用户逐项填写修改后，附原图做局部编辑。编辑提示词由本机服务按版本校验后拼装，并冻结到生图记录。
- **兼容性**：之前逆向的版本没有可编辑元素，需重新逆向才能使用原图编辑，文生图不受影响。逆向并生图、批量完整复刻和轻量面板保持文生图。

## 主体外观与姿态更具体

- **外貌按部位写**：所有逆向路径先写主体类别，例如「成人东亚女性」「成年橘色短毛猫」「哑光陶瓷马克杯」，再写服装、发型、毛色等外层造型，最后逐个部位写形状、大小、颜色与状态，例如「杏仁大眼，柔和平眉，细窄鼻梁，饱满微张裸粉唇」，并使用美妆、发型、服装和产品工艺的行业词。
- **写实照片的成像特征**：写实照片额外写清晰度分布（焦点落在哪些部位、哪些边缘柔化）、修图程度和贯穿背景、光与后期的色调主词。
- **多个主体逐个绑定**：每个主体以画面位置加主体类别起句，外貌只写在自己的句子里；共享的光、色调和清晰度只写一次。
- **轻微侧身和转头不再被画成正面**：逆向时按头、视线、肩胸、骨盆逐段比较左右两侧的可见证据，定出方向和近似角度，例如「上身向画面右侧转约 30°，画面左侧肩膀靠近镜头、显得更宽；脸转回约 15°，目光看向镜头」。偏转是辨识关键时，排除项写明「双肩正对镜头，身体端正对称」。物体和动物同样记录朝向与可见面。
- **认得出的角色、地标与产品直接写名字**：逆向时先识别画面中的已知角色、吉祥物、地标、艺术作品或产品型号，用发型、瞳色、标志饰物、建筑轮廓、产品外形等稳定标志核对，确认后在主体类别后写出专名，例如「日向雏田（Hinata Hyuga，《火影忍者》）」，帮助生图模型认准对象，观察摘要里写明识别依据。同人图换了服装或画风也能认出。具名后，与原作一致的脸型五官、发型发色、瞳色和体型只简写成一个短语，避免细节描述把角色画偏；与原作不同的服装饰品等，以及神态、姿态朝向、构图、光色和画风仍照图写。原图编辑的可编辑元素不受影响，仍完整描述外观。只凭 Agent 已有知识识别，不联网；想不出具体候选时只写外观。真实人物不按长相认人具名。
- **原图编辑的元素更细**：可编辑元素把脸部、妆容、姿势和背景分开列出，「当前」值用部位短语描述，姿势写各段朝向与角度；有人物时必列脸部特征与姿势。
- **原图编辑更忠于原图**：编辑提示词除了逐项写修改，还把没改的元素按「当前」描述列为「保持不变」，并要求身份、各部位朝向角度、构图机位、光色与材质等修改未涉及的方面与原图一致；保持项与修改冲突时以修改为准。修改只波及必然连带的局部，例如新衣物的褶皱与投影。
- 重新逆向后才应用新规则，已有提示词不自动改写。

## 修复

- 「设置中心 › 生图渠道」载入为 Magpie 后立即改选其他渠道时，较慢的设备上「保存生图设置」可能一直不可点，需重新选择渠道才恢复。改选渠道会结束尚未开始的 Magpie 模型读取，保存按钮随即可用。
