## 升级方式与数据

本版需要同步更新完整仓库中的本机服务与浏览器扩展，无新增浏览器权限。已有项目、历史结果、配对和配置保留，无需手工迁移或重新配对，不修改 Codex 全局配置，也不自动归并已有重复项目。

1. 保存重要编辑，等待任务完成或主动取消后，在原 `browser-extension` 目录执行 `npm stop`；前台服务请在原终端停止。
2. 保留本地改动与 `.local/` 数据，将完整仓库更新到 `v0.3.3`，执行 `npm run setup`、`npm start`，核对 `npm run status` 为 `0.3.3`、`ready: true`。
3. 重新加载原扩展，刷新工作台和已打开网页，确认扩展版本为 `0.3.3`。使用 ZIP 时解压到原扩展加载目录，不删除原扩展或清空浏览器数据。

首次启用插件内重启功能需先手动重启旧服务。Chrome ZIP 只含浏览器端，不含 bridge 与运行 skill，首次安装和本次服务升级均需完整仓库。轻量端未提交草稿不承诺跨浏览器重启保留。详见[安装与升级指引](https://github.com/AIDiscovery007/qc-reframe/blob/v0.3.3/browser-extension/docs/INSTALL_WITH_CODEX.md)。
