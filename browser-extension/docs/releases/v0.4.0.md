# QC-Reframe v0.4.0 · 会话创作、正文搜索与 CLI 恢复

2026-10-06 · 从 Codex 会话中选择故事，用参考图赋予画面风格。

## 会话创作

- 工作台新增「会话创作」路径：一张参考图提供风格，最多五条完整 Codex 会话提供人物与故事内容，沿用现有画布、提示词版本与生图流程。
- 会话选择支持标题搜索、分页及归档范围。已选会话独立置顶，切换搜索、分页或归档范围后仍可查看和移除；候选列表独立滚动，确认操作保持可见。
- 读取与当前 CLI 相同 `CODEX_HOME` 下的会话，仅采集用户文字与助手最终回复。附件只记录数量，不读取图片内容；完整正文不传给前端，明确提交创作任务后才将所选文字交给模型。
- 更改选择后需重新逆向；历史结果保留当时的来源快照，重新逆向读取新快照。读取失败、输入冲突和大小限制明确提示，不以摘要替代完整正文或静默截断。
- 关闭选择窗口或切换搜索会取消旧读取；超时、取消与迟到结果不会覆盖新状态。任务已提交但响应丢失时，提示前往任务中心确认，避免重复提交。

## 标题与本地正文搜索

- 标题搜索使用独立只读连接，支持短时缓存、输入防抖、取消与分页。按需启用「标题和正文」，建立本地正文索引，无需调用模型。
- 正文搜索覆盖用户文字与助手最终回复，支持中文、英文片段与多关键词，展示简短原文命中；选择单位仍是完整会话。索引在后台工作线程中运行，兼容 Node.js 22.15。
- 索引提供真实进度、可搜索数量、失败原因、增量同步及每日正文复查。可停止、清除和重建；部分缺失与整体不可用分别提示，构建期间新结果随进度出现。
- 修复工具日志被误计入正文限额的问题；单页过大时减少每页对话轮数，从同一位置重试，保留总量、页数和超时边界，不截断已选内容。
- 进度完成后自动收起，保留数量和手动展开；失败与重建时展开。搜索、选择、返回设置后的草稿与焦点保留，沿用当前组件、布局及减少动态效果偏好。

正文搜索是词面检索，不是语义向量搜索；首次索引耗时取决于本机会话规模。索引只保存在本地，可清除后重建，不删除 Codex 源会话或已提交任务的创作快照。

## 更准确的人物描述

- 人物适用的逆向路径补充体型、四肢长短粗细、轮廓与比例等具体描述，中英文保持相当的表达强度。
- 按输入角色与用户意图区分身份体型、画风比例、服装和透视，不默认瘦身、拉长腿部或补造不可见身体；会话创作不会把风格参考图中的体型直接套给故事人物。
- 新规则在更新服务并重新逆向后生效，已有历史版本与手动编辑的提示词保持原样。

## CLI 初始化、兼容检查与升级恢复

- CLI 未安装、未登录或缺少旧版接口时，初始化仍可构建维护界面，引导在原有设置中处理；Node.js 与运行 skill 的必要检查，以及独立 `doctor` 检查仍保持严格。
- 「Codex 与更新」分别展示版本更新与功能兼容性。只读检查实际 CLI 的接口描述，按模型、逆向、生图、会话功能分别判断；未知结果允许实际尝试，明确不支持时仅限制对应功能，不因版本号旧而关闭整个工作台。
- 展示实际 CLI 路径，按原安装渠道引导升级，保留自定义 `CODEX_BIN`；App 或自定义来源的 npm 稳定版本只作参考，不据此覆盖用户安装。
- 升级后等待版本与接口复查、清除旧模型验证状态，区分「升级失败」与「已升级但复检未完成」。重新检测后，由用户验证模型并重试原操作，不自动提交任务。
- 网络、账号、模型、额度和接口错误分别给出可用的恢复入口。服务在线只表示已连接；文字模型验证也不代表生图权限与额度已经通过。
- 错误可直接前往现有设置的对应分类；设置已打开或连续前往同一分类也能正确导航。返回后保留项目输入、会话选择与搜索草稿。
- 慢兼容检查不再阻塞其他任务取消；取消或断开后停止自身等待，迟到结果不继续读取或写入。CLI 升级与正在读取的操作仍互斥，任务提交前重新核对输入版本。

## 升级方式与数据

本版需要同步更新完整仓库中的本机服务与浏览器扩展，相较 v0.3.x 无新增浏览器权限。已有项目、历史结果、配对与配置保留，无需手工迁移或重新配对，不修改 Codex 全局配置。

1. 保存重要编辑，等待任务完成或主动取消后，在原 `browser-extension` 目录执行 `npm stop`；前台服务请在原终端停止。
2. 保留本地改动与 `.local/` 数据，将完整仓库更新到 `v0.4.0`，执行 `npm run setup`、`npm start`，核对 `npm run status` 为 `0.4.0`、`ready: true`。
3. 重新加载原扩展，刷新工作台和已打开网页，确认扩展版本为 `0.4.0`。使用 ZIP 时解压到原扩展加载目录，不删除原扩展或清空浏览器数据。

Chrome ZIP 只含浏览器端，不含 bridge 与运行 skill；只替换 ZIP 无法启用本版服务能力。已支持插件内重启的托管服务，也可在源码更新和构建完成后通过「设置中心 → 本机连接」重启；该按钮不下载更新、不重载扩展。CLI 更新、Reframe 服务更新、扩展重载和网页刷新需分别完成。轻量端未提交草稿不承诺跨浏览器重启保留。详见[安装与升级指引](https://github.com/AIDiscovery007/qc-reframe/blob/v0.4.0/browser-extension/docs/INSTALL_WITH_CODEX.md)。
