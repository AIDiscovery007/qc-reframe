# QC-Reframe v0.4.3 · 逆向并生图与清晰图片预览

2026-10-08 · 逆向完成后接续生图，图片预览控制栏不再遮挡画面。

## 创作流程与图片预览

- 新增「逆向并生图」：提交后先生成提示词，再使用当次输入、顺序、语言、比例与模型继续生成图片；仍保留「仅逆向 / 更新提示词」和独立「生成图片 / 再生成图片」。通用风格没有主体图时只能仅逆向。
- 逆向与生图分别显示进度并支持取消；生图失败保留已完成的提示词，可重试或独立生成。切换项目后的迟到响应不会切回当前上下文；重复生图保留独立历史。旧版服务不支持自动续接时明确提示本次仅逆向。
- 工作台与轻量窗口保留提交、取消、失败恢复时的键盘焦点，并覆盖主动转焦和切换项目的行为。
- 图片预览的缩放、适配和旋转控件移至独立控制行，避免覆盖图片信息；宽屏、竖图、窄屏、短视口与只读结果均保留完整查看、缩放、平移和返回入口的操作。

## 开发与验证改进

- 开发阶段前置受影响场景与关键风险复核，定稿后执行完整必要门禁。自动缩减建议当前仅覆盖专用图片查看器样式，业务影响不明确时回退全量，不把文件归属当作完整依赖图。
- 提供同机证据核验，检查源码、构建、测试资料、检查器、环境、报告附件和必要覆盖；失配、缺失、过期、取消或未声明跳过时拒绝复用。独立风险复核和视觉审阅仍保留。
- 工具自测保留代表正例和故障反例，正常产品路径由完整门禁覆盖；统一构建与验证窗口，CI 一次选择 browser 或 full，并记录阶段、场景耗时和重跑原因。

## 升级方式与数据

从 v0.4.2 升级需同步完整仓库中的本机服务和浏览器扩展；「逆向并生图」包含服务端接续能力，Chrome ZIP 不含本机服务和技能，不能只替换 ZIP。

1. 保存编辑，等待任务完成或主动取消后，在原 `browser-extension` 目录执行 `npm stop`；前台服务在原终端停止。
2. 保留本地改动与 `.local/` 数据，将完整仓库更新到 `v0.4.3`，执行 `npm run setup`、`npm start`，确认 `npm run status` 显示 `0.4.3`、`ready: true`。
3. 重新加载原扩展，刷新工作台和已打开网页，确认扩展版本为 `0.4.3`。使用 ZIP 时解压到原加载目录，不删除原扩展或清空浏览器数据。

已支持插件内重启的托管服务，可在源码更新和构建完成后通过「设置中心 → 本机连接」重启；该按钮不下载更新、不重载扩展。本版不新增浏览器权限，不要求手工迁移或重新配对；项目、提示词、生成图片、历史输入顺序、配对及配置保持。服务重启不会补跑中断的自动生图。轻量端未提交草稿不承诺跨浏览器重启保留。详见[安装与升级指引](https://github.com/AIDiscovery007/qc-reframe/blob/v0.4.3/browser-extension/docs/INSTALL_WITH_CODEX.md)。
