**In English:** install with one command on macOS and Linux, or hand the copy-paste prompt in the [README](https://github.com/AIDiscovery007/qc-reframe/blob/v0.7.0/README.md) to any agent. The extension now has a fixed ID, so a copy loaded from any folder or ZIP connects by itself. On macOS, Chrome and the Codex built-in browser start the local service on demand. Upgrading from v0.6.0 or earlier: update your copy, remove the old extension once and load the new `.output/chrome-mv3`. Projects, prompts, images and settings are kept.

## 一条命令安装

macOS 与 Linux 在终端运行：

```bash
curl -fsSL https://github.com/AIDiscovery007/qc-reframe/releases/latest/download/install.sh | bash
```

- 安装器下载 Release 运行包 `qc-reframe-runtime.tar.gz`（已构建的扩展、本机服务和 Alchemy skill），按同一 Release 的 `SHA256SUMS` 校验后安装到 `~/QC-Reframe`，再执行 `npm run setup`、`npm start`。之后只需在浏览器加载一次打印的 `.output/chrome-mv3`。
- 重新运行同一命令即升级：只替换运行包里的文件，保留 `.local/`（项目、配对与配置）和目录中的其他文件。安装或升级在复制中途被打断时，重新运行即可完成。下载或校验失败不改动任何文件；指向非运行包的非空目录会被拒绝。
- `QC_REFRAME_DIR` 指定安装目录，`QC_REFRAME_VERSION` 安装指定版本。Windows 仍从源码安装。
- 首页改为英文 [README](https://github.com/AIDiscovery007/qc-reframe/blob/v0.7.0/README.md) 与中文 [README.zh-CN](https://github.com/AIDiscovery007/qc-reframe/blob/v0.7.0/README.zh-CN.md)：可复制给 Codex、Claude Code 等任意 Agent 的安装提示词、一条命令安装和分步使用说明。

## 从任意目录加载都能自动连接

- 扩展 manifest 带固定公钥，从任何目录或 ZIP 加载的 QC-Reframe ID 都是 `lmnmccbogohpiagjbmpaiagaoddhkpgf`，本机服务自动识别，无需填写配对码。另行签名的构建仍可用 `ALCHEMY_EXTENSION_ID` 明确批准一个额外 ID。
- 服务离线时，工作台和轻量端显示一条可复制的启动命令。服务使用自定义数据目录（`ALCHEMY_DATA_DIR`）时，命令会带上该目录，在新终端粘贴即打开原来的项目，不会落到空的默认目录。网页上的逆向面板不显示安装路径。

## macOS：Chrome 与 Codex 打开即启动

- `npm run setup` 为已安装的 Chrome 和 Codex 各注册一次按需启动器，打开 Reframe 时自动启动已停止的服务。2026-11-26 已在 macOS 真机验证：Chrome、Codex 内置浏览器各自都能唤醒服务。
- 升级后，`npm start` 与启动器会自动停止本安装的旧版本服务并启动新版；任务执行中则保留旧服务并说明原因。由终端前台启动的服务仍需在原终端停止。
- 原安装目录已删除或移动时，`setup` 会替换失效的启动器注册；属于另一份有效安装的注册仍会跳过，撤销命令只删除本安装自己的注册。
- 启动器等待服务就绪期间不再触发 Codex CLI 状态检查。

## 工程与发布

- CI 改为每次改动运行完整回归，并按改动分为文档、本机服务与完整三条线路，必需检查更名为 `ci`。
- 新增 Release 工作流：只对 main 上通过完整回归的标签发布，附 Chrome ZIP、运行包、`install.sh` 和 `SHA256SUMS`；可手动演练而不发布。

## 升级方式与数据

**一键安装的用户：** 等任务结束后重新运行安装命令，再在扩展管理页点 QC-Reframe 的重新加载按钮，并刷新已打开的网页。

**从 v0.6.0 或更早的源码安装升级：**

1. 保存编辑，等待任务完成或主动取消，在原 `browser-extension` 目录执行 `npm stop`；前台服务从原终端停止。
2. 保留本地改动与整个 `.local/`，将完整仓库更新到 `v0.7.0`，执行 `npm run setup`、`npm start`，核对 `npm run status` 为 `0.7.0`、`ready: true`。macOS 上 `setup` 会同时注册 Chrome 与 Codex 启动器。
3. **扩展 ID 改为固定值，旧扩展不再获得连接凭据。** 在扩展管理页移除旧的 QC-Reframe，再加载新的 `.output/chrome-mv3`，按浏览器提示确认权限，并刷新工作台和已打开网页。Chrome 与 Codex 内置浏览器分别操作。

本版不新增扩展权限，无需数据迁移。项目、提示词、图片、生图渠道与服务配置保存在 `.local/`，全部保留；移除旧扩展只会重置一次扩展内的本地偏好和未提交草稿。不修改 Codex 或 Pi 的全局配置。
