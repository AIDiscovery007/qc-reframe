# QC-Reframe v0.4.4 · 批量完整复刻与稳定操作栏

2026-10-09 · 一次选中多个项目，自动完成提示词逆向和图片生成。

## 批量完整复刻

- 工作台「全部项目 → 批量管理」新增「批量完整复刻」。统一设置提示词语言与图片比例，预检逐项说明能否启动；提交时重新校验，仅接收合格项目。首版只覆盖完整复刻，不上传主体图；逆向分析已保存参考图，生图仅使用生成的文字提示词。
- 所有批次共享最多两条完整流程，依次完成逆向和一张图片生成；保留原有手动单项行为。队列由本机服务持久保存，关闭工作台后继续执行，使用提交时的输入、指令、模型、语言和比例快照。
- 任务中心展示排队、逆向、生图和最终结果，可取消单项或「停止剩余」排队项目。单项失败不影响其他项目；生图失败保留已完成的提示词。响应丢失时重试沿用原请求，避免重复启动。
- 排队项目纳入忙碌、删除、模型切换和素材引用保护。服务异常重启后把未完成流程标记中断，不自动重跑；存储失败保留可恢复状态。

## 操作栏修复

- 「隐藏所选」「恢复所选」「删除所选」使用无底色文字按钮，禁用状态也不显示灰底块，保留原生按钮语义与键盘焦点提示。
- 修复中文被挤成竖排，以及勾选数量变化导致操作栏和项目列表跳动的问题。按钮按内容占宽，窄屏按完整按钮换行；主操作继续使用亮黄强调。
- 修复全部项目受理后的焦点返回、跨窗口隐藏后的预检显示和提交过滤；未知受理结果的重试仍保持原请求身份。

## 开发与 CI

- 文档白名单改动使用轻量检查；产品改动通过统一入口选择测试，缺少可信映射或依赖范围不明确时回退全量。
- GitHub Actions 增加每小时完整回归，核对实际受检提交、最新运行尝试和可信报告；不把旧提交结果或未受信任来源当作当前合并证据。

## 升级方式与数据

从 v0.4.3 或更早版本升级，需同时更新完整仓库中的本机服务和扩展。Chrome ZIP 只含浏览器端，不含 bridge 或运行技能；首次安装也需要完整仓库。

1. 保存编辑，等待正在运行和排队的任务全部结束，或主动取消后，在原 `browser-extension` 目录执行 `npm stop`；前台服务在原终端停止。
2. 保留本地改动和 `.local/` 数据，将完整仓库更新到 `v0.4.4`，执行 `npm run setup`、`npm start`；核对 `npm run status` 显示 `0.4.4`、`ready: true`。
3. 重新加载原扩展，刷新工作台与已打开网页，确认扩展版本为 `0.4.4`。使用 ZIP 时解压到原加载目录，不删除扩展或清空浏览器数据。

已支持插件内重启的托管服务，也可在更新代码和构建后通过「设置中心 → 本机连接」重启；此按钮不下载更新、不重载扩展。本版无新增浏览器权限，无需手工迁移数据或重新配对；既有项目、提示词、图片、配对和配置保留。服务重启不自动补跑中断批次或自动生图。未提交的轻量端草稿不承诺跨浏览器重启保留。详见[安装与升级指引](https://github.com/AIDiscovery007/qc-reframe/blob/v0.4.4/browser-extension/docs/INSTALL_WITH_CODEX.md)。

## 验证与限制

- 功能定稿阶段完整回归通过：854 项 Node 测试、75 个浏览器场景和 16 项隔离 MV3 检查。操作栏覆盖 360、650、651、877、1440px，卡片与列表、包含隐藏项目以及未选、单选、多选、全选和取消选择。
- 发布包另按 `npm run zip`、`npm run compile`、`npm test` 和生产构建浏览器门禁验收；核对 ZIP 与受测目录一致、manifest 版本及内容边界。附件 `SHA256SUMS` 使用 ZIP 文件名，可用于校验下载内容。
- 验证使用合成项目、stub 模型与临时浏览器，不调用真实模型、不重启用户现用服务或重载已安装扩展；不代表真实账户额度、模型质量或已有安装环境验收。
- 保留三项已声明限制：两处只读图片预览没有旋转操作，一处 macOS 原生下拉框键盘能力未验证。触屏、屏幕阅读器、closed ShadowRoot 内部几何和三项核心产品像素基线仍有未覆盖或待人工审阅内容。远端 CI 以实际运行记录为准。
