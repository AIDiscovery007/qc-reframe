## 创作工作台与作品画廊

输入与结果采用等宽双画布，标签、图片、图条和操作区对齐，图片完整居中；提示词展开时两侧同步调整，窄屏可切换输入与结果。模式、图片操作与提示词版本集中在图条下方，语言、编辑、导出、目标尺寸和生图操作按需展开。

左侧「作品画廊」按真实图片比例汇集跨项目生成结果，可搜索、筛选、预览原图并回到来源版本；分页、视口附近渲染和按需缩略图支持长列表浏览。完成提醒提供未读标记、静默桌面通知和可选提示音；隐藏项目默认不进入画廊或弹出提醒，小眼睛切换查看范围，隐藏与恢复操作支持撤销。

## Codex 全流程

**在 Codex 内置浏览器选图，通过本机 Codex CLI 直接交互，再用 Codex 直接生成图片。** 扩展将选中的图片和任务指令交给本机 `codex app-server`；逆向后可编辑、复制中英文提示词，或继续调用 Codex 内置 `image_gen` 生图。无需填写另一套模型 API Key，沿用 Codex 登录与额度。

插件可独立选择并验证模型，不修改 Codex 全局模型设置。Codex 内置浏览器是已有验证环境，也支持 Chrome 使用路径；不同客户端的扩展加载入口可能不同。内置生图需要本机 imagegen skill 及账户能力支持。

[安装到 Codex 内置浏览器](INSTALL_WITH_CODEX.md#codex-内置浏览器) · [生图与模型说明](../README.md#一键生成图片)

## 先放大细看，再写词

**内置 Alchemy skill，要求每次逆向先完成观察。** 整图定位后，调用只读图像工具裁切、放大关键区域，核查主体特征、材质、笔触、光影和边缘，再回看整体关系，组织成可执行的提示词。多张输入按各自职责分别观察。

局部工具只处理当次输入，不修改原图。放大帮助辨认已有细节；源图无法分辨的内容会记录为限制。工具不可用时按技能的降级规则说明，不把未完成的细查描述为已完成。

## 单图到多图

四条路径，按创作意图选择：

| 路径 | 图像分工 | 适合做什么 |
| --- | --- | --- |
| 提取风格 | 单图提取通用画法；加入主体后保留主体结构，迁移参考画法 | 水彩化、材质与配色迁移 |
| 完整复刻 | 参考图用于逆向；生图仅使用提示词与排除项 | 将画面重建为可复用的文字描述 |
| 主体重演 | 主体图提供身份，模板提供构图、姿态与视觉表现 | 让自己的人物或物品演绎参考图 |
| 多图重演 | 2–6 张主体按顺序提供身份、物品、服饰、场景或细节，另加一张模板 | 将多个输入编排进同一张画面 |

任务指令可编辑，以你的指令决定保留和迁移什么。多图支持批量上传、逐图分工、换序与替换；逆向后继续生成图片，也可基于提示词再生成更多版本。

## 浮窗三种入口

网页图片旁的 Reframe 图标展开三个入口，让浏览与创作按你的节奏衔接：

| 入口 | 下一步 |
| --- | --- |
| 立即逆向 | 打开当前图片的逆向面板，选择路径并提交任务 |
| 加入 Reframe | 只保存参考图，继续浏览；稍后从「待逆向」集中处理 |
| 打开工作台 | 直接进入宽版创作界面，管理已有项目 |

加入图片不调用模型；打开工作台也不会自动收集图片或开始逆向。浮窗、工具栏弹窗与工作台共用项目和任务，已提交任务在关闭面板后继续运行。

## CLI 版本探针

**检测插件实际调用的 Codex CLI。** 设置中心展示版本与安装来源，并提供检查更新；已确认来源、满足条件的独立安装版、npm、Homebrew 安装可一键升级。

App 内置与无法确认来源的自定义安装显示相应更新指引。更新桌面 App 不等于更新独立 CLI；升级成功后会刷新模型目录，再验证模型即可继续使用。已有逆向、生图和模型验证任务完成后才能升级。

[CLI 检测、升级与安装来源](../README.md#轻量界面与工作台)

## 多任务并行

**多个项目、路径和提示词版本可以同时逆向或生图。** 每项任务有独立进度、取消操作与结果，任务中心集中查看；无需守着一个面板等任务结束。

同一提示词版本的生图进行中会防止重复提交。关闭界面不取消任务；停止本机服务或关机会中断未完成任务。历史版本与已完成结果保存在项目中。

[任务与版本管理](../README.md#模板项目与版本) · [并发与数据说明](../README.md#图片与数据)

## 图片直接在本机打开

生成结果已保存到本机。在结果区复制图片路径，继续交给其他创作工具；macOS 还可以一键用默认应用打开图片，或在 Finder 中定位文件，无需再下载一份。

操作始终对应当前选中的生成记录。其他系统可复制路径，直接打开与文件夹定位目前仅支持 macOS。

[本机图片操作](../README.md#一键生成图片)

## 成果留在本机

图片、提示词、生成记录和日志按用途存入 `browser-extension/.local/`。项目库支持搜索、分页、待逆向筛选与批量隐藏；提示词版本和生成历史可继续使用，已提交生图保留当次输入与提示词快照。

![项目库：搜索、隐藏管理与参考图收纳](releases/v0.1.21-projects.png)

*v0.1.21 示例界面。*

本机保存不代表离线推理：选中的图片会按 Codex 配置交给模型处理。服务停止后备份整个 `.local/`，可保留配置与项目。

[数据目录、备份与图片存储](../README.md#图片与数据) · [项目管理](../README.md#模板项目与版本)

## 图片方向就地调整

**准备输入时，在预览里左右旋转 90°，点击「应用旋转」即可继续。** 调整后的实际图片直接用于后续逆向与生图，省去下载、调整、重新上传的往返。

![图片预览：左转、右转与应用旋转](releases/v0.1.21-rotation.png)

*v0.1.21 示例界面。*

关闭未应用的预览会保留原输入。历史输入与生成结果不被改写；多图主体修改后须重新逆向。主体与参考图还支持一键互换，普通预览支持缩放、拖拽和适应窗口。
