# QC-Reframe 插件开发指引

作用域为 `browser-extension/` 及其子目录。先遵循上级指令和用户当前要求；本文记录已有产品决策，用户明确调整方向时同步更新。统一协作准则和岗位定义索引见根目录 [AGENTS.md](../AGENTS.md)，当前协作会话及日志索引见[动态任职表](../.agents/roles/assignments.md)；任务详情与复核结论写入 [agent-logs/](../agent-logs/) 的对应会话日志，不追加到准则或任职表；工程、GitHub、文档拆分和发布流程见 [Contribution.md](../Contribution.md)。根目录 `AGENTS.md` 维护协作规则，本文维护插件工程约束，两者不重复维护。

本文用于代码开发与仓库维护，不是图片逆向任务的提示词。插件运行时的逆向或生图任务按显式输入与对应技能完成，不因读取本文而执行仓库维护或发布操作。

## 接手任务

- 先读 [README.md](README.md) 和[更新日志索引](docs/releases/README.md)，再按任务读取代码。版本以 [package.json](package.json) 为准，测试数量与旧发布记录不构成本次验证。
- 探索前明确问题、范围、输出量与分工成本。优先 `rg` 定向查找；独立读取可并行，依赖操作按顺序执行。避免转储 `.local/`、日志、图片字节或全仓内容。
- 编写精简、直接的代码，复用已有组件和模块；不为小改动增加抽象、依赖或复制一套相同逻辑。
- 新克隆不包含作者本地设计提取、图片和运行配置。不得依赖作者机器路径，也不要为恢复开发环境清空现有数据。

## 产品与兼容性

公开名称为 **QC-Reframe**，npm 包为 `qc-reframe-extension`，仓库为 [qc-reframe](https://github.com/AIDiscovery007/qc-reframe)。由原名称更名时保留了内部 `alchemy:*` 消息、`qc-alchemy` 服务标识、`ALCHEMY_*` 环境变量，以及独立的 `alchemy` 技能名。不要对旧名字全仓机械替换；需要改协议时同时考虑旧配置、存储与迁移测试。

这是 WXT + React + TypeScript 的 Chrome MV3 扩展。目标是“网页选图 → 本机 Codex 逆向提示词 → 用户按需生成图片”；不内置模型 API Key，不修改用户 Codex 全局模型配置。Codex 内置浏览器是已有验证目标，同时保留 Chrome 使用路径；本机 Agent 仍可能调用云端模型。

### 五条路径的职责

| 模式 | 输入与默认行为 |
| --- | --- |
| `style` 提取风格 | 可仅提取参考图的通用风格；也可上传主体，保留图 1 的内容、结构、姿态和构图，仅迁移图 2 的画法。 |
| `recreate` 完整复刻 | 逆向时分析参考图的内容、构图和视觉表现；生图时仅发送提示词与排除项，不附图、不读取参考图，使用纯文生图。 |
| `reenact` 主体重演 | 图 1 提供主体身份，图 2 提供风格、构图、姿态、表情和内容关系。第三项是预填且可编辑的任务指令，不要求先生成另一条 Prompt。 |
| `multi-reenact` 多图重演 | 2–6 张主体按编排顺序提供身份、物品、服饰、场景或细节，最后一张参考模板提供画风、构图、姿态与关系，融合为同一画面。 |
| `session` 会话创作 | 单张参考图仅提供风格；用户勾选完整会话，以当前创作目标和会话文字上下文生成专属提示词，再沿用单图生图与结果展示。无需主体图，不使用 `[SUBJECT]` 或双图分工。 |

五条路径共用 `TaskInstruction` 组件，均提供可编辑任务指令；完整复刻和仅提取通用风格也提交当前指令。指令通过顶层 `instruction` 保存，兼容旧 `reenact.basePrompt`；草稿按项目、路径和提示词版本隔离，旋转或互换参考图时随输入保留。用户编辑的任务指令优先于默认分工。双图路径发送顺序始终是主体图、参考模板；其专属提示词明确两张图职责，不留下 `[SUBJECT]`。通用风格可保留占位符，但补充主体并生成专属提示词前不能直接一键生图。不能宣称恢复了原始 Prompt 或保证逐像素复刻。

多图重演采用已确认的「模板编排」方案：大模板、横向主体缩略图、选中主体的用途和保留特征，支持批量上传、替换、前后移动与删除。每张主体上传后压缩到 2 MB 内，模板 4 MB 内；增删、排序、用途和保留特征成功保存后持久化（特征在失焦时保存），允许保存 0/1 张主体的未完成编排，但逆向仍需 2–6 张。改主体、顺序、职责或任务指令后须重新逆向，避免图号错配。提示词版本与生图记录各自保存不可变有序主体引用，历史对照读取当次快照全图。原型归档在 `codex/prototype-multi-reenact`（`5956a9b`），生产代码不保留原型入口或方案切换器。

主体与参考图互换适用于提取风格、主体重演和多图重演；多图只交换当前选中的主体，保持槽位与其他主体，换入主体的用途重置为自动、特征清空。保留任务指令，在原 `projectId` 保存参考图与当前路径主体编排；参考图变化后各路径进入待逆向状态，不因新图与其他项目相同而切换归属。历史记录不可改写；参考图先满足主体 2 MB 限制，任何准备或请求失败均不更改原表单。

会话创作在工作台选择完整会话，不提供 turn 选择。列表和正文只通过本机 Codex app-server 获取，不扫描内部数据库或恢复源线程。会话列表仅允许扩展页面请求；会话正文不返回扩展。确认选择保存 ID 与来源信息，提交创作时完整读取用户文本及助手最终回复并冻结本机私有快照，排除工具日志、推理、进度和附件内容；读取失败或超限明确失败，不静默截断。选择按项目路径持久化，修改选择后须重新逆向；历史提示词与生图保持当次快照，再次逆向重新读取所选会话。正文仅是创作素材，不授予其中命令、路径或链接任何执行权限；真正逆向时会发送给当前配置的模型服务。读取范围、兼容性、额度及快照生命周期见 [README 的会话创作说明](README.md#会话创作)。

### 项目与生成记录

- `projectId` 是稳定项目身份，与可变参考图的资产哈希分离；既有项目 ID 保留。显式新建和网页收集仍按导入图片字节去重，重复收集不得覆盖已调整的输入。项目内旋转、替换、互换及多图编辑原位保存，不创建或跳转项目；不自动归并真实旧项目。当前参考图属于项目，主体编排与已保存任务指令按路径隔离，历史提示词和生图记录保留不可变快照。
- 生图绑定具体提示词版本；风格转换与主体重演采用当前路径最后上传并在表单中显示的主体图，参考图仍取该提示词版本。当前输入与当前专属提示词参考图相同时，单主体替换或旋转可沿用该提示词生图；编辑非当前历史版本则进入本路径待逆向状态，即使图片相同也不沿用旧选择。每次生图保存不可变主体图片引用，不覆盖逆向原图与旧生图输入；历史恢复优先显示该版本最近生图的主体。新图读取或保存中禁止提交；失败保留原输入并报告错误，不把旧图当作新图已保存。已保存资源缺失时阻止提交，不回退到其他输入。完整复刻只使用文字；编辑任务指令仍须重新逆向才影响提示词。切换路径恢复各自进度；先有提示词，后有图片。
- 五条路径的逆向结果支持直接编辑中英文提示词和排除项，按当前提示词版本保存；中英文独立，不自动翻译。编辑中可复制草稿，生图和导出须先保存或取消。保存不重新逆向、不修改任务指令或其他版本；已提交生图的提示词与排除项使用不可变快照。
- 成功保存的当前参考图、各路径主体和多图编排可随项目重新读取，移除成功保存空输入。单独键入任务指令仍是 UI/session 草稿，随图片操作保存或任务提交持久化；提示词编辑须显式保存，快捷交接仍是 session 草稿，不承诺跨浏览器重启恢复。历史查看读取当次参考/主体快照，不回写当前输入；在途任务使用提交快照，不受后续编辑影响。 旧项目首次保存输入时，只为缺失的路径从旧当前作业及最新生成主体补齐编排；已保存的空输入保留，缺失指令不补空串遮蔽客户端默认。
- 输入更新携带 `inputRevision` 拒绝跨窗口旧写入，提交也校验输入版本；当前输入成功保存为新逆向任务时递增 revision，历史同图再次逆向不覆盖当前输入或已有版本指针；前端按项目/路径/版本上下文丢弃过期响应，失败保留旧输入。服务重启优先保留合法项目归属与当前输入，仅为缺失归属的旧记录补齐身份，不按历史图片重新拆分已有项目。
- 网页Reframe logo按钮展开「立即逆向 / 加入 Reframe / 打开工作台」三个入口；打开工作台只发送现有 `alchemy:open-workspace` 消息，不选图、不收集、不推理。「加入 Reframe」只保存/复用参考图项目，不打开面板、不修改当前项目或选图状态、不调用模型；图片右键也保留加入与直接打开面板两条路径。收集需本机服务运行且已配对，无离线队列；同捕获字节按既有 SHA256 规则去重，持久保存完成后才显示成功。打开项目和切换路径不自动触发推理。逆向与生图可跨项目、路径和提示词版本并行，每项任务使用独立 Codex 进程、进度与取消信号；关闭面板不取消任务。仅同一提示词版本的生图防重复提交，任务执行期间限制模型切换；模型验证期间暂不提交新任务。保留失败与重启恢复状态，并行写入须有序且原子保存，避免结果覆盖。
- 运行数据目录由 `bridge/storage.mjs` 管理：`.local/config/` 保存配对与设置，`records/` 保存项目/任务及删除恢复记录，`images/` 保存共享图片，`logs/` 保存日志，`runtime/` 保存启动锁。仅在旧服务停止后迁移已知文件；同名冲突保留双方并报错。管理命令兼容读取根部旧配置，禁止在状态查询或旧服务仍运行时迁移。正常运行不产生开发测试资料。日志达到 5 MB 时在下次启动轮替，仅保留上一份。
- 图片由 `bridge/images.mjs` 统一按内容 SHA256 存入 `.local/images/`；项目、任务及生图记录保存 `imageAsset` / `subjectAsset`，多图任务还保存 `reenact.subjects[].subjectAsset` 与 `generations[].subjects[].subjectAsset`；不同角色可共享同一文件。保持文件不可变、路径校验和并行写入合并；旧记录先原子迁移引用并校验内容，再清理旧文件。共享文件回收扫描项目当前参考图、各路径主体/多图编排、历史任务及生图快照的持久引用，在启动时或所有图片任务结束且持有请求变更锁时执行；损坏记录或未完成迁移阻止回收，避免误删。 输入已成功落盘后，资源回收失败保留 `collectionPending` 稍后重试，不将回收错误报告为输入保存失败。
- 单个或批量删除项目须沿用现有确认与忙碌保护，只清理插件保存的副本，不删除用户上传原件或 Codex 原始生成文件。存储改动必须保护旧记录与重启恢复。
- 图片已经由本机服务保存，结果保留“复制图片路径”，macOS 另提供“打开图片”和“在文件夹中显示”，不要恢复成误导性的“下载图片”。打开操作只传任务与生图记录 ID，由 bridge 解析并校验已保存图片；不接受前端路径或命令。排除项随 Prompt 送入生图，观察边界留在分析结果，不擅自混入视觉指令。

- 项目 `hidden` 状态持久保存在 bridge，旧记录默认可见；隐藏过滤在项目分页、搜索、任务列表截取前执行。扩展 session 的显示开关由共用「包含隐藏项目」小眼睛统一控制，默认闭眼、包含时睁眼；指针操作成功后180ms过渡，键盘/减少动态效果即时，失败不改变图形；浏览器重启默认收起；全部项目、侧栏、任务中心、当前详情与任务徽标遵循同一开关。隐藏不取消任务，服务内部忙碌计数仍保留全量，避免绕过模型/CLI 互斥。运行中项目允许隐藏，但不能删除。常规卡片/列表浏览不显示勾选与批量栏；进入批量管理才出现。单项隐藏/恢复靠近项目，详情隐藏后返回可见视图；成功反馈提供撤销，仅作用实际更新且原状态需要变更的项目。部分成功保留未更新选择，失败保留状态与重试能力；操作同步防重入，旧响应不得覆盖新详情。范围切换失败在当前模态或页面内可读。隐藏只过滤 selection 的可见性，不清除持久选择，避免并发切项目时误删新选择。
- 项目库通过服务端分页/搜索读取摘要，每页 24 个，侧栏仅最近 12 个；「全部 / 待逆向」筛选在分页前执行，待逆向指 jobCount 为 0，切换筛选回第一页并清空批量选择；列表摘要包含封面引用，不为卡片读取完整历史。项目任务索引与摘要缓存随持久化和进度变化失效；全局及单项目 revision 区分服务重启。隐藏界面暂停轮询，恢复后立即刷新。
- 工作台项目库支持卡片/列表切换，默认卡片，显示偏好保存在扩展页面本地存储。列表仅在进入批量管理后展示复选框与批量操作；切换视图复用同一项目组件、缩略图和选择状态，不重置搜索、筛选或分页，返回卡片时有选择则保持管理状态。
- 缩略图属于可重建派生缓存，由 `bridge/thumbnails.mjs` 保存到 `.local/cache/thumbnails/v1/`；保留原图与不可变图片引用，源图回收后清理对应缓存。分页、搜索与键盘切换不加过场动画；指针按压复用约 120ms 反馈，遵循减少动态效果偏好。

## 代码入口

| 文件或目录 | 职责 |
| --- | --- |
| `entrypoints/content.ts`、`lib/image-action-placement.ts` | 网页选图、悬浮按钮避让、closed Shadow DOM 浮层及焦点行为。 |
| `entrypoints/background.ts`、`lib/bridge.ts`、`lib/client.ts` | 扩展消息、配对、受限后台请求；令牌留在扩展后台。 |
| `entrypoints/popup/`、`entrypoints/workspace/` | 共用 React 业务界面；轻量浮层/弹窗保留，独立扩展工作台提供分栏、任务中心及宽版设置。 |
| `bridge/cli.mjs` | 实际 CLI 来源、版本、每日检查及受限独立版/npm/Homebrew 升级；与模型和任务互斥。 |
| `bridge/server.mjs`、`bridge/projects.mjs`、`bridge/images.mjs`、`bridge/storage.mjs` | 本机 HTTP 服务、任务与项目持久化、共享图片存储、迁移与回收。 |
| `bridge/codex-rpc.mjs`、`bridge/agent.mjs` | Codex CLI app-server stdio JSON-RPC、图片与 skill 输入、逆向结果校验。 |
| `bridge/sessions.mjs`、`entrypoints/workspace/SessionPicker.tsx` | 本机会话列表与整会话选择、正文过滤及私有快照；通过既有后台与 bridge 鉴权链路访问。 |
| `bridge/inspection.mjs` | 逆向专用只读图像工具；仅按当次输入编号裁切、放大和取样，内存返回图像与元信息。 |
| `bridge/models.mjs`、`bridge/model-context.mjs` | 动态模型目录、真实验证、选择保存与账号/CLI 上下文检查。 |
| `bridge/generation.mjs` | 按路径以纯文字、单张风格参考图或主体与参考图组合，携带 Prompt 调用 imagegen，读取真实图片结果。 |
| `.agents/skills/alchemy/` | 随仓库分发的运行技能及必要参考文档。修改技能时维护伴随引用，不引入私人案例。 |
| `scripts/manage.mjs`、`scripts/preview.mjs`、`tests/` | 安装及服务管理、明确标记的 UI 示例、隔离的自动测试。 |

## 连接、模型和图片边界

- 逆向、生图与模型验证的 `thread/start` 默认设置 `ephemeral: true`；结果从实时事件获取并保存到 Reframe，不依赖 Codex 会话日志。仅显式设置 `ALCHEMY_PERSIST_CODEX_SESSIONS=1` 时为逆向/生图保留会话，模型验证始终临时；开关只作用于当前服务进程，不写入运行配置。失败或取消不回退持久会话。旧会话仅按已保存的 thread ID 核对并归档，不按提示词标题清理。

- bridge 默认仅监听 `127.0.0.1:43187`，保留配对认证、Host / Origin 和消息来源检查。页面内容不能任意请求本机文件或端点；不将配对码暴露到页面 DOM。
- 模型目录取自插件实际调用的本机 CLI；列表出现不等于账号有权限。验证成功才保存插件选择，失败保留原有效选择；账号、登录、提供方或 CLI 变化需重新确认上下文。不要硬编码“可用模型”，不要悄悄回退到全局默认模型。
- CLI 管理只允许固定认证端点，已确认来源的独立版/npm/Homebrew 可更新；独立版校验包元数据与稳定入口，固定执行原 CLI 的 codex update；App/custom 保留原安装方式。检测对应 manager 与运行时，升级与任务/验证互斥，成功后清除模型信任并刷新目录；失败保留错误，不声称升级成功。定时检查只读，手动按钮才执行升级。
- 独立安装的 Codex CLI 与桌面 App 更新是两回事；检查 `CODEX_BIN` 实际指向。API / 协议变化需核对实际 CLI 能力和官方文档，不根据模型名字推断支持情况。
- Agent 通过显式图片和技能输入运行，保留只读 sandbox 与不自动批准交互式工具的约束。逆向输出仍需结构校验，不把任意模型文本当成可信控制命令。
- 逆向注册 `alchemy_inspect_image` 动态工具；只接受本次输入图号与区域参数，不接受路径或 URL，使用 EXIF 校正后的原图像素坐标。工具在内存中裁切、放大和采样，不写文件；仅处理本会话已注册的工具调用，其他交互请求仍拒绝。生图与模型验证不注册此工具。技能的观察验收条件统一维护在 `references/workflow.md`，最终 observations 是摘要，不是分析深度上限。
- `functions.exec` 可能将动态工具返回值转成元信息与 PNG data URL 拼接的字符串；工具说明携带经过测试的 `showInspection` 示例，兼容字符串和结构化图像块，禁止将整个返回值或 base64 打印成文字。展示失败优先复用当前结果，不重新调用图片工具。进度区分整图、局部目标倍率与失败；调用成功不等于模型已经查看图像，真实验收须检查视觉输入。
- 多图主体字节保存在 bridge 图片库；扩展 local 只保留任务指令与任务引用，避免超过存储配额。未提交草稿的工作台交接仍受 8 MB 会话上限保护。
- 生图调用用户本机的 imagegen skill 与内置 `image_gen`；只认真实 `imageGeneration` 完成结果，不把聊天中提及的路径当成图片。能力不可用时明确失败，不改用需要 API Key 的生图脚本或其他接口。
- 只处理用户选中的图片与任务输入，不采集网页正文、cookie 或登录数据。资源读取失败时只在已有规则允许下截取目标图片区域，不把整个网页送去模型。保持输入大小限制和路径校验。
- `.local/`、设计提取与构建产物始终按 ignore 规则保留在本地。切勿把真实用户数据加入测试 fixture，或从日志中复制 token 到文档。

## UI 与品牌约定

- 带蒙板的原生弹窗统一通过 `lib/motion-dialog.ts` 启用 `closedby="any"`，不支持时按蒙板边界和完整指针手势兼容处理；关闭请求复用各组件的 cancel 回调和忙碌保护。内部空白、内容操作和向外拖拽不触发关闭，叠层仅关闭最上层。

当前设计保留 Raft 的暖白底色与亮色选中态，以留白、浅色表面和文字层级划分内容。页面不使用贯穿黑线、重复卡片描边、画布网点或硬阴影；仅表单输入与图片选中保留必要的浅色边界，浮层使用柔和阴影。样式以 [style.css](entrypoints/popup/style.css) 和 [shell.css](entrypoints/popup/shell.css) 为准；`design-extract-output/raft-build-prompts` 如存在仅作本地参考，不是依赖。

- 主要色值：背景 `#faf9f6`、表面 `#fffefa`、次级表面 `#f0ede6`、文字 `#26241f`、浅边界 `#e5e1d8`、亮黄 `#ffd440`、粉色 `#fe7da8`、青色 `#27ccf3`。路径选中态沿用现有黄、粉、青、紫（`#ccbafa`）等模式样式。优先使用已有 CSS 变量，不平行建立第二套 token。
- 保持中文文案简洁、状态一读就懂。全局不展示重复解释控件用途的常驻辅助文案，图片标题旁只保留角色标签，旋转工具栏只保留操作与异常状态；表单标签、必要操作条件、错误、进度、记录信息和删除后果保持清晰。网页浮层只在顶栏显示一次品牌，不增加重复的大标题、解释按钮含义的长段落或开发实现术语；空态、错误和禁用原因须明确。
- 低频纯文字帮助复用 `InlineHelp.tsx` 的原生 `details/summary`：悬停预览并保留点击、触屏和键盘展开路径，不仅依赖 `title`。安装诊断等长内容用原生折叠区；关键费用、错误、禁用条件及删除后果不收进帮助。零任务数量、未使用路径状态、重复完成状态和无内容的只读排除项不常驻显示。
- 按用户要求，插件各界面和网页悬浮按钮不显示点击、输入或键盘聚焦产生的额外 outline；保留控件常规边框、选中与错误状态，以及原有键盘操作和焦点恢复逻辑。
- 品牌唯一源图为 [reframe.svg](assets/brand/reframe.svg)，经 `lib/brand.ts` 内嵌到 UI；`npm run icons` 生成 16/32/48/96/128 px 图标，build / zip 自动执行。改 logo 时同时检查工具栏、悬浮按钮、面板、弹窗和文档，不只替换一个 PNG。
- 所有下拉框复用 `SelectField.tsx`。当前约定为高 40px、标签间距 8px、箭头 16px、距右边框 12px、文本右内边距 40px；保留原生键盘、Escape、焦点与禁用交互。
- 指针按压反馈约 120ms，指针打开浮层轻移 18px / 淡入 180ms；键盘打开、路径和语言切换即时完成。尊重 reduced motion，Escape 返回有效触发器；不要给普通切换增加等待。
- 共用交互动效在 `entrypoints/popup/motion.css`：按钮和文件选择按压 120ms，原生对话框入场 200ms、缩放至 .97，原点靠近有效触发器；状态和展开内容只作短淡入。使用 starting-style 避免从键盘换回指针时重播已有内容，旧浏览器直接显示。对话框沿用 `lib/motion-dialog.ts` 的即时关闭和当前 Document / ShadowRoot 焦点恢复，不等待退场再执行操作。复制成功保留固定按钮尺寸、勾号与颜色；网页入口只缩放图标，不改液态圆面或点击区域。
- 网页入口仅显示 32px 品牌 logo，保留 40px 透明点击区域，不加外圈、底色或悬停背景；展开三项使用主题亮黄圆面、墨色线性图片 SVG（立即逆向）、加号（加入 Reframe）和分栏窗口（打开工作台），保留 aria-label 与 title。入库状态使用呼吸点/勾号和原通知反馈，不在按钮中插入文字。触发器不直接保存。
- 展开坐标由 `lib/image-menu-placement.ts` 统一计算，优先朝图片内部散开，窄图使用直线排列；同时检查图片与视口边界、网页控件及命中遮挡。无安全空间时隐藏入口，保留图片右键路径。滚动、图片失效或位置实质变化时关闭，正常轮询不截断菜单/动画，不比较 CSS 坐标字符串；使用 focusin 判断新焦点，避免 focusout 与点击竞争。上下方向键、Home/End、Escape、Tab 与焦点恢复继续有效。
- 液态表面使用固定版本 liquid-gooey 0.2.2，仅在本地绘制三个主题亮黄圆形，无黑色描边；收起时缩为零，入口不绘制额外底形。首次显示入口时挂载，无持续物理引擎；指针展开/收回 240ms，重复输入可中断，键盘与减少动态效果即时完成。卸载时清理 React root；不增加外部资源或权限。
- 收集反馈由真实保存状态驱动：按压及时反馈，等待使用呼吸点，成功显示勾号和已加入/已存在提示，失败提供重试；连续收集不阻塞其他图片。成功提示默认 4 秒，页面隐藏、鼠标悬停或焦点进入提示时暂停计时；减少动态效果时取消非必要运动，保留静态状态与文字。
- 轻量浮层和工具栏弹窗始终保留，所有工作台入口共用 `lib/workspace-navigation.ts` 串行导航：复用已有 `workspace.html` 标签并在页内处理路由，仅无工作台时新建；不重载已有工作台。共用 App/表单/任务逻辑，草稿通过 trusted session storage 一次性交接，配对令牌不进入交接数据。参考原型保留在 `codex/prototype-settings` 的 `60d352d`，实现分支不带原型源码。
- 轻量两端复用 QuickWorkspace，提供提示词阅读、语言切换、复制及当前生图结果；完整提示词编辑、排除项、导出与历史对照在工作台完成。不展示“视觉观察、观察边界”，分析数据保留于记录和 Markdown 导出。共用画廊样式在 `popup/result-gallery.css`，工作台专属效果样式留在 `workspace/results.css`。
- 网页悬窗为非模态界面，不锁住宿主页面。打开后仍保留网页图片入口，按钮与展开菜单将悬窗和通知的实际边界视为障碍；被完全覆盖或空间不足才隐藏。仅隔离插件内控件事件冒泡，不阻止网页控件默认行为；关闭面板释放避让范围。
- 工作台生图前可选择预设或自定义宽高比例；轻量生图沿用当前提示词版本最近一次生图的比例，没有记录时使用自动，调整尺寸须进入工作台；通过 `aspectRatio` 传至 bridge，校验后追加到本次不可变 Prompt，保持原逆向提示词不变。默认自动，不传比例；自定义宽高为 1–10000 整数，比例范围 1:20–20:1。比例是提示词约束，不承诺精确像素或比例，不后处理裁剪/拉伸。结果尺寸来自图片元数据，结果行仅展示像素尺寸和实际比例，不显示目标比例或解释文字；历史比例绑定生图记录。
- 异步进度复用原操作区域：工作台与轻量两端逆向进度和取消集中在紧凑指令框，提示词为空时不渲染占位面板；生图在原操作位置展示状态和取消，不在图片或表单上方插入进度条。设置说明与任务状态行保留稳定空间；轻量呼吸点仅表达任务仍在执行，不模拟百分比，减少动态效果时静止。
- 轻量两端使用固定 180px 透明画布、36px 图条和图条下方紧凑工具栏，图片保持 contain。图条切换参考/主体，替换、互换和移除集中在工具栏；多图编排转到工作台。放大入口悬浮于实际图片右下角。可放大的非品牌图片通过 `ImagePreview.tsx` / `ImagePreviewButton` 共用图片预览和 `ImageViewer.tsx` 的缩放拖拽；放大入口统一使用 34px 图标按钮，距实际可见图片右、下边缘各 4px；工作台、轻量输入、多图编排、组合预览、单张结果和结果对照均复用共享定位。通过 ResizeObserver 与图片 load/error 更新 contain 边界，加载或失败时隐藏入口，卸载时清理监听；不锚定留白容器边缘。沿用 120ms 按压与 200ms 预览开启动效，键盘和减少动态效果即时响应，关闭不等待动画；项目库（卡片及列表）、最近项目与任务中心的缩略图只打开对应项目或记录，不提供图片预览入口；批量选择使用复选框。工作台生成记录缩略图只切换当前结果，不打开预览，大结果图保留放大功能；选择主体仍使用兄弟预览按钮，不嵌套按钮。列表不再为图片预览读取原图。弹窗在当前 `.app` 内挂载，兼容 Shadow DOM 与任务中心叠层；Escape 仅关闭预览并恢复触发器焦点，关闭后的异步结果不得影响下一次预览。缩放与拖拽直接跟随输入、不加补间，沿用平移边界、指针取消及监听器清理。
- 只有准备输入（含多图组合画面及轻量表单）的预览传入 `ImageRotation` 能力。旋转按原始字节执行 90° 整数倍，交换宽高、不裁剪；预览多次调整均从打开时原图重算，转回零度保留原始字节。显式应用后在原项目保存参考图或当前路径主体编排，保留任务指令；参考图变化使各路径进入待逆向，多图主体变化须重新逆向，不覆盖历史或在途快照。主体沿用 2 MB、参考图 4 MB 限制。失败保留原输入，应用中禁止关闭，输入切换后关闭过期编辑预览；只读预览不传旋转回调。
- 工作台结果区采用已确认的推挤式抽屉：空内容隐藏，提交即展开并压缩编辑区，主动收起后完成仅提示新结果；开合状态按项目/模式/提示词版本隔离。图片区无底板，顶部以同高角色标签和当前版本/图片编号区分两侧，底部保留浅色圆角纯图标工具条；轻量面板仅展示当前结果与快捷生图，完整历史和对照由工作台承接。复用 GenerationEffect 像素等待与揭晓、ImagePreview/ImageViewer 缩放拖拽，不用原型预览替换。抽屉内画布保持最终宽度，输入与结果采用等宽双列、共用标签/画布/图条/操作区轨道；图片无额外内边距，揭晓按相同 contain 几何对齐，避免出图时改变像素坐标；收起停止动效挂载，后台任务继续。提交请求回包前复用 LoadingPlaceholder 显示等待反馈，pending 状态随对应上下文保留，回包后接回原生成动效。左侧项目栏独立展开/收起，收起保留可访问的导航和项目缩略图，窄屏默认收起；结果抽屉只挤压编辑区。窄屏通过输入画布/生成结果切换单工作区，关闭侧 inert，键盘/减少动效即时开合。已确认原型归档在 `codex/prototype-result-drawer`（`db01eb63f4747e2ecc3d8f575b5589b5c7619ec3`），正式入口不保留演示控件。
- 工作台采用用户选定的方案 A「对齐双画布」（`CanvasWorkspace.tsx` / `canvas-workspace.css` / `results.css`）：两侧等宽，标签、图片、图条与底部操作区共享基线，图片 object-fit contain；图条下方无边框工具栏集中模式、图片操作、多图设置与版本，提示词入口位于指令框左下。长提示词展开时两侧同步预留空间，文字滚动不挤偏单侧图片。沿用真实项目/版本/指令/主体状态，区分已保存项目输入和未保存编辑；替换参考图和互换在原项目持久保存，不覆盖历史。此前 C 画布原型归档于 `codex/prototype-canvas-sheet`（`34d94a1741f1a07396d181a52c28e904c97e742f`），正式入口不保留演示控件。
- 工作台指令框加高并支持跨栏放大，保留紧凑生成/更新/取消按钮。提示词面板采用方案 B：跨工作区宽度，支持放大/恢复，结果开合不限制编辑宽度；`useEditorExpansion.ts` 共用同一 DOM 的 320ms FLIP，中断先读取当前可见几何再取消旧动画。顶层浮层保持祖先主题与状态，恢复后返回原槽位；隐藏的窄屏输入区不得让浮层遮挡结果。外部指针按下与点击都在面板外且无拖动才收起，不拦截新焦点，草稿仍须显式保存/取消。提示词为空时隐藏面板，完成逆向自动展开；`PromptSheet.tsx` 负责 300ms 上滑、指针直跟、向上阻力、下拉 >60px / 有效轻甩关闭和 420ms 弹簧回弹。中断从当前位移继续；pointercancel/lostcapture 回到打开，隐藏/失焦/尺寸变化即时稳定，卸载释放动画与捕获。键盘/减少动态效果即时，关闭返回开关焦点。面板保持挂载，不中断 GenerationPanel 或丢失草稿；打开时画布、图条与指令区 inert，并预留面板空间；工具栏保持可达，图片操作禁用，仍可切换上下文。
- 提示词工具条集中语言、复制、Markdown 导出与编辑，保留排除项。生图和目标尺寸复用 GenerationPanel，以 portal 进入底部面板；模式/版本选择始终可达，尺寸与生成历史仍按原记录恢复。指令与多图编排变化先更新提示词，通用风格须有主体才能生成专属提示词；「仅提取风格」显式调用不带主体的 start("style")。编辑期间禁用重新逆向、导出和生图，保留复制草稿。
- 工作台遵循已选宽版方案：紧凑标题、项目导航、输入/提示词与结果分栏、独立设置中心；不恢复已删除的 WORKSPACE 路径标题、静态输入说明和视觉观察区。原图对照读取生图不可变快照，缺失明确报错，不回退最新上传图。
- 生图动效只由工作台入口注入，img-fx / three 按需加载，不打入 content 脚本。使用公开引擎接口绕开自动轮播与全局图片缓存；真实任务完成且图片就绪后才揭晓，动画不决定任务成功。保持完整图片比例，取消/失败/卸载释放资源，后台与离屏暂停；生图等待与揭晓统一遵循下述全局动效设置，减少动态效果时静态等待、图片可用后直接显示，WebGL 不可用时降级为静态像素画面。生成中不显示画布等待文案、转圈或顶部进度提示条，取消入口在结果底部工具栏；失败/取消提示保留。img-fx 固定 0.5.1，升级时复核揭晓裁切补偿与资源清理。
- 工作台 `LoadingEffect` 管理通用像素等待、尺寸、可见性和资源释放，`GenerationEffect` 仅管理生图揭晓。共用 UI 通过 `LoadingPlaceholder` 的 Context 接入，由工作台入口注入实现，禁止把 img-fx 引入 content 包。轻量两端逆向阶段和取消位于紧凑指令框，使用不依赖效果 Provider 的反馈；工作台只在当前逆向运行且无结果时播放提示词等待效果。取消按任务 ID 防重复提交，失败显示错误并允许重试。参考图／多图模板仅在当前路径无图且无读取错误时播放。通用像素等待与生图统一遵循全局动效设置，后台与离屏暂停，WebGL 不可用时静态回退；内容可用立即移除等待，不覆盖旧正文，不给按钮和列表逐项创建 Canvas。
- 全局动效由 `lib/motion-preference.ts` 统一解析：设置中心「界面与动效 → 减少动态效果」提供跟随系统（默认）、开启、关闭；独立存储于 `browser.storage.local.motionPreference`，由后台通过受校验的 runtime 消息读写，仅公开该偏好；后台向扩展页和网页顶层脚本发送变更通知，再读取最新值。local 保持 TRUSTED_CONTEXTS，不向网页开放含 token 的存储，不依赖本机服务。工作台、轻量面板、网页液态菜单与收集反馈均使用该有效偏好，不直接以系统媒体查询覆盖用户选择；CSS 仅作用于插件 `.app` 或 Shadow host，不修改网页或系统设置。
- 共用组件 CSS 统一由 `entrypoints/popup/style.css` 的 `@import` 汇总，网页浮层通过 `style.css?inline` 注入 ShadowRoot。不要在共用 React 组件中直接导入 CSS：构建会将其注入网页外层，导致浮层丢样式并污染宿主页面。工作台专属样式仍由工作台入口加载。
- 结果面板使用当前 Shadow DOM 方案和普通工具栏弹窗，不重新引入此前不兼容的原生 sidePanel 或扩展 iframe 依赖。预览中的 iframe 是测试容器，不能视作运行时方案。
- 大范围 UI 重构先用有限原型明确方向；已有确认方案直接落实。任务适用且环境提供设计 skill 时使用它；普通文案修正和已确定的缺陷修复不另设审批流程。

## 验证与完成

在本目录运行 `npm run build` → `npm run compile` → `npm test`；扩展测试依赖当前构建。按改动增加回归测试，覆盖路径隔离、旧数据恢复、消息认证、模型选择等真实风险，不写仅镜像实现的测试。纯文档改动按 Contribution.md 检查即可。

UI 使用 `npm run preview` 检查相关空态、等待、失败、已有结果与窄屏状态；再按任务范围验证真实扩展。预览不能代替浏览器权限和跨域验收。工具若无法操作 closed Shadow DOM 或扩展管理页面，说明实际限制并保留待人工验证项，不绕过限制、不虚报成功。

服务升级先确认无运行任务，再用管理脚本重启，保留数据和配对；扩展更新需要重新加载原目录并刷新网页。真实模型调用只在本次任务授权范围内执行。最后按 [Contribution.md](../Contribution.md) 更新对应文档、检查提交范围、同步或发布，并给出简短中文交付说明。

- 轻量两端共用 `QuickWorkspace.tsx`：180px固定画布、36px图条、紧凑悬浮工具栏；版本入口在无当前结果时仍可用。保留单/双图快捷逆向、语言/复制、当前结果、一键生图和取消；多图编排、完整编辑、尺寸、历史与设置进入工作台。快捷生图不得跳过 generic/incomplete/inputsReady/busy/running 约束，复用已有尺寸；上传或保存失败保留旧主体并显示错误，切上下文释放忙碌并忽略旧响应。
