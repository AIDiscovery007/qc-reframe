将网页中选中的图片交给本机 Codex，通过现有 `alchemy` 技能逆向为提示词。使用 WXT 官方 React + TypeScript 模板、Manifest V3。

## 轻量界面与工作台

工作台左侧「全部项目」上方的「作品画廊」汇集所有项目已完成且图片文件可读取的生成结果。按图片真实宽高排列为自由瀑布流，支持搜索项目或作品、项目与横竖方图筛选、时间排序和密度切换。点击作品预览原图，查看尺寸、模式、提示词版本和生成时间；「查看所在项目」直接定位到该模式、版本和生成记录。隐藏项目默认不计入作品与项目总数，点击睁开小眼睛「包含隐藏项目」后显示来源标识。 画廊页头与全部项目、项目详情共用位置和尺寸，滚动作品时保持固定；作品统计置于内容区。

画廊每页读取 96 条摘要，只挂载视口附近的卡片；缩略图按需读取、限制并发并使用有上限的缓存，打开预览才读取该作品原图。窗口或密度变化保留阅读位置，结果更新后重新核对分页版本。新增接口需要在任务结束后重启本机服务，并重新加载原扩展、刷新工作台；无需迁移历史项目。

带蒙板的弹窗均可点击蒙板关闭，包括新建项目、设置、任务中心、删除确认、生成信息和图片预览。点击弹窗内的内容或空白处不会关闭；叠层只关闭最上层。读取参考图、删除项目或应用旋转期间，沿用原有的暂时禁止关闭保护。

网页内悬浮面板和工具栏弹窗复用画布、图条与快捷工具，采用适合小窗口的固定图片展示高度，图片按比例适应。快捷功能保留参考/主体上传、互换与移除、模式和提示词版本切换、任务指令、逆向与取消、提示词语言/复制，以及一键生图、当前结果与取消生图。快捷生图沿用当前版本最近一次目标尺寸，没有记录时使用默认尺寸；通用风格和缺少主体时先完成专属提示词。多图编排、完整提示词编辑、目标尺寸设置、历史对照和项目/设置管理在工作台继续。

工作台结果区采用推挤式抽屉：没有内容时隐藏，提交生图即从右侧推出并收窄编辑区；可随时收起，任务继续运行，收起后完成仅显示「新结果」入口。展开状态按项目、路径和提示词版本分别保存于当前页面。展开后采用方案 A「对齐双画布」：左右等宽，共享标签、图片、图条和操作区的行高与基线；同纵横比图片显示尺寸一致，不同比例完整居中、不裁切。图片直接置于暖白背景，顶部轻量区分输入与生成结果；图条居中，模式、替换和版本入口位于左侧操作区，任务指令与提示词入口位于其下。右侧操作区显示版本与尺寸，底部保留浅色圆角纯图标工具条（对照原图、打开图片、在文件夹中显示、复制路径、生成信息）。展开提示词时两侧画布同步收缩，保持对齐。请求提交尚未回包时显示像素等待与「正在提交生成请求…」，切换项目返回仍能恢复等待，提交失败保留错误及已有图片。生成中的像素等待、完成揭晓以及现有图片缩放拖拽预览继续复用原组件。

网页悬窗打开后仍可操作和滚动网页，图片上的 Reframe 入口继续保留，并避让悬窗与通知；收集另一张图不会切换当前项目。点击「工作台」接续明确的源项目、模式、当前提示词版本和未提交输入，不受其他窗口切换影响。快捷草稿按弹窗/网页标签页隔离，保存在扩展会话中，重新打开可恢复；交接只转移一份图片草稿，失败保留原草稿，不写入项目历史，不启动任务。临时草稿24小时过期，关闭浏览器后不保证恢复；空间不足明确提示。

两种界面共用项目、四条路径、提示词版本与后台任务。工作台可上传参考图新建项目、替换主体、编辑提示词、对照当次生图的原图、放大结果及查看生成时的提示词快照。任务中心列出所有活跃任务和最近 30 个逆向版本的记录，可单独取消任务；更早记录仍可在项目中查看。项目栏顶部的图标支持展开或收起；收起后保留导航图标和项目缩略图，悬停可查看项目名称。窄屏下通过「输入 / 结果」切换单画布，结果区占满工作区；键盘操作和减少动态效果设置使用即时切换。

鼠标和触摸按压控件时提供短暂回弹；设置、任务、图片预览和确认窗口从触发位置轻微展开。复制完成在原按钮中显示勾号与成功色，读取图片和异步任务保留原操作位置的状态反馈。键盘打开与高频切换即时完成，减少动态效果时保留静态反馈；关闭窗口不等待动画。网页液态菜单和下述生图画布继续沿用各自效果。

工作台生图时在当前结果画布播放像素动效，真实结果图片读取完成后揭晓一次，随后释放动效资源。历史结果不重播；取消、失败或图片读取失败时回到对应状态提示。动效仅在工作台需要时加载，不进入网页浮层脚本；隐藏或离开画布时暂停；生图画布遵循全局动效设置，减少动态效果或 WebGL 不可用时降级为静态像素画面，真实图片就绪后直接显示。生成画布不显示重复的等待文案、转圈或进度条，取消操作保留在结果底部工具栏，详细阶段可在任务中心查看。动效基于 MIT 许可的 [img-fx](https://github.com/Jakubantalik/img-fx)，不改变生图输入或结果文件。

工作台在逆向提示词的空面板、参考图或模板恢复的空图框复用像素等待效果，并保留真实状态文字。逆向中的阶段文字和取消入口集中在指令区；网页轻量浮层使用可读的阶段反馈，完成后可展开提示词。内容就绪后立即移除占位；失败与取消停止动画。这些像素等待与生图画布统一遵循全局动效设置；后台与离屏暂停，WebGL 不可用时保留静态占位。

在「设置中心 → 界面与动效 → 减少动态效果」选择跟随系统（默认）、开启或关闭。开启后加载像素、图片揭晓、弹窗、按钮与网页液态菜单使用静态反馈；关闭后播放完整动效，即使系统启用了减少动态效果。选择自动保存在扩展本地并同步到已打开的工作台与网页浮层，不改变系统设置，也不影响逆向或生图任务。

设置中心按 Codex CLI、模型、连接、本地数据分类。打开设置时检测实际 CLI 安装，独立安装版、npm/Homebrew 安装每天后台检查一次可升级版本；也可手动「检查更新」。确认安装来源及实际可执行路径后，可直接点击升级按钮。升级期间拒绝新的逆向、生图、模型验证和停止服务；已有任务完成后才能升级。升级成功会刷新模型目录，需重新验证模型。检查失败不会标为最新版本。

独立安装版校验安装包元数据、稳定入口和自更新命令能力后，通过原 CLI 的 `codex update` 更新；不切换到 npm 或覆盖其他安装。固定到某个版本文件的 CODEX_BIN 需先改为安装器创建的稳定入口。重新检测会显示完成结果与安装检测时间，更新检查失败单独提示。

App 内置和无法确认来源的自定义安装只显示版本及原安装方式的更新指引，不尝试覆盖。CLI 缺失或未登录时仍可通过 `npm start` 启动本机管理服务；首次 `setup` 与 `doctor` 保留严格环境检查。升级命令只由本机服务固定生成，不接受网页传入命令或路径，不使用 sudo。关闭工作台不会取消任务或升级。

模型选择与 CLI 上下文关联；外部更新 CLI 后，同路径二进制或 npm 包版本变化会使旧验证失效，需要重新验证。仅从 v0.1.25 更新至本版不会新增模型验证要求。

## 先收集，稍后逆向

浏览 Pinterest 等网页时，图片旁只显示 32px Reframe logo（40px 透明点击区域，无外圈）。点击后液态展开三个亮黄主题色图标按钮：图片图标用于「立即逆向」，加号用于「加入 Reframe」，分栏窗口图标用于「打开工作台」；悬停可查看名称。打开工作台会进入独立标签页，不收集当前网页图片、不开始逆向。菜单根据入口位置朝图片内部展开，窄图自动改为直线排列，同时避让网站控件并保持在图片和视口内；空间不足时可使用图片右键菜单。加入只保存参考图，不打开面板、不切换当前项目、不调用模型；保存中、成功和失败均有通知，可以继续浏览收集其他图片。

菜单展开后，鼠标移到另一张图片会立即收起旧菜单，仅在新图显示 R 按钮；再次点击才展开新图操作。移入菜单按钮或仍在原图内移动不会收起。

点击图标后立即显示保存状态；呼吸点表示仍在保存，勾号表示已成功加入，重复图片提示已存在，失败时可点击重试。成功提示默认显示 4 秒，鼠标停留、键盘焦点进入提示或页面隐藏时暂停倒计时；系统启用减少动态效果时保留静态状态反馈。

稍后打开「项目记录」，切到「待逆向」即可找到尚未创建逆向任务的图片。筛选在分页前执行，可继续搜索标题或来源；切换筛选回到第一页。已开始逆向的项目归入「全部」，失败任务也可在那里继续处理。

收集需要本机服务已启动且扩展已配对连接，没有离线队列；连接失败不会显示保存成功。同一份捕获图片字节复用已有项目，已保存图片在服务重启后仍保留。收集无需验证模型，开始逆向前再完成模型验证。

## 模板项目与版本

工作台「全部项目」支持在工具栏切换「卡片 / 列表」，并记住本机浏览器的显示偏好。「全部 / 待逆向」与视图切换、批量管理置于同一工具栏，窄屏自动换行；页头和工具栏固定，项目内容独立滚动。列表紧凑展示封面、标题、来源、逆向状态和更新时间；两种视图均在「批量管理」后显示勾选框与批量操作。切换显示方式保留搜索、筛选、页码与当前选择。

在项目卡片、列表或详情中点击「隐藏」即可收起项目，成功后可「撤销」。反馈以浮层提示呈现，不占页面布局：可撤销提示保留 6 秒，撤销成功后保留 4 秒；悬停、键盘聚焦、页面隐藏或操作处理中暂停计时，错误保留到手动关闭。点击睁开小眼睛「包含隐藏项目」可在项目库、最近项目、搜索结果和任务中心找回隐藏项，再点击「恢复」。批量管理支持「隐藏所选」「恢复所选」；混合选择只修改需要变更的项目，未成功项保留选择以便重试，撤销只恢复实际更新项。轻量面板通过工作台进行项目管理。隐藏状态保存在本机项目中，重启服务仍保留；显示开关在当前浏览器会话内共用，重启浏览器后默认收起。隐藏不删除图片或提示词，也不中断正在执行的任务。

- 以捕获后的参考图片字节 SHA256 识别项目，不按网页地址分组；同一图片从不同网页选中可复用，同图经过不同压缩、尺寸或裁剪可能成为不同项目。
- 「项目记录」每页展示 24 个项目，支持搜索全部项目的标题或来源；返回列表保留当前界面内的页码和搜索条件。批量管理中的「选择本页」包含当前页可见项目，运行中的项目可隐藏，删除须等待任务结束，删除末页后自动回到有效页。工作台侧栏只展示最近 12 个项目。
- 项目卡片、侧栏、任务中心和历史生成缩略图按可见区域读取最长边 480px 的 WebP 缩略图；打开详情仍使用完整图片。工作台封面优先显示最近生成结果，参考图作为回退。缩略图首次读取时生成并保存到 `.local/cache/thumbnails/v1/`，不修改原图，可重新生成；源图回收后同步清理对应缓存。
- 插件内的输入图、主体编排、生成结果大图和对照图片支持放大预览。项目库（卡片及列表）、最近项目与任务中心的缩略图用于打开对应项目或记录，不进入图片预览；批量选择仍使用复选框。工作台生成记录缩略图只切换当前结果，不触发放大。放大按钮统一悬浮于实际图片右下角，随图片等比适配后的边界定位；选择主体与放大使用独立按钮。预览支持缩放、拖动和适应窗口，Escape 关闭后回到原操作位置。
- 界面有活跃任务时约每 2 秒检查进度，空闲时约每 10 秒检查变化；项目列表与详情仅在版本变化后重新读取，详情未变化不重复传输历史。隐藏界面时暂停轮询，重新可见时立即检查，后台任务继续执行。服务仍在启动时读取全部任务元数据，尚未改为数据库或历史按需读取。
- 选中项目会成为当前项目，刷新或重新打开浮层仍可读取本机保存的路径记录。
- 四条路径独立保存已提交的主体图和任务指令，不把风格路径的输入带入主体重演。切换路径时当前表单草稿保留；关闭、切换项目或进入项目列表时，未提交的草稿不持久保存。
- 各路径默认展示最新逆向版本；通过「本路径逆向版本」可查看更早的提示词及其生图记录。每张生成图片始终绑定具体逆向版本；重新逆向后，新版本从待生图开始。
- 空路径只带入公共参考模板，提示词与图片显示待生成。提示词完成后才开放生图；通用风格仍需补充主体并生成专属提示词。
- 服务启动自动迁移全部旧任务（不受旧历史列表 30 条限制），补充项目归属和共享图片引用；原提示词、输入与生成图片内容保留。项目模板独立引用图片，尚未逆向的新项目也能在重启后恢复。旧模板文件已缺失时仍保留记录并提示恢复原图。

项目记录支持单独删除、复选框多选与全选删除。确认后移除所选项目全部路径和版本的提示词、生图记录；插件 `.local` 内的共享图片仅在没有任何项目或任务引用时回收。其他任务正在运行时，图片回收延后至任务结束；用户原始上传文件、另存到其他目录的下载和 Codex 原始生成文件不受影响。正在执行任务的项目暂不能删除。删除中断会在服务重启时继续清理，重新选择相同参考图会建立空项目。

## 首次使用

要求：可加载 MV3 扩展的浏览器、Node.js 22.15+、已安装并登录的 Codex CLI。首发在 macOS 验证。

```bash
cd browser-extension
npm run setup
npm start
npm run pair
```

`setup` 检查环境、安装锁定依赖并构建；Alchemy 运行 skill 已随仓库提供。`start` 后台启动本机服务，重复运行复用现有服务和配对码；`pair` 显示本机配对码。`npm run status` 查看状态，`npm stop` 停止服务并保留数据。重启电脑后再次运行 `npm start`。

1. 在 Codex 内置浏览器的扩展管理中加载 `.output/chrome-mv3`（支持 ZIP 的客户端也可导入 Release 的 Chrome ZIP）。首次加载及权限确认可能需要用户手动完成。
2. Chrome 则打开 `chrome://extensions`，启用开发者模式并加载该目录。不同浏览器分别安装。
3. 打开 QC-Reframe 设置，粘贴本机配对码并连接。在「插件模型」选择模型，点击「验证并使用」。
4. 打开或刷新 Pinterest 等网页，悬停图片点击 Reframe 圆形图标，将图片加入项目库后继续浏览。
5. 在「项目记录 → 待逆向」打开图片，选择路径生成提示词，再按需生成图片；也可用图片右键菜单直接打开逆向面板。

首次默认「提取风格」，选中参考图后上传自己的主体图，再生成风格转换提示词；「完整复刻」只使用参考图。加入图片、打开项目和切换路径均不会自动开始逆向，需点击生成按钮。支持并行任务：任务执行中可继续选新图、切换项目或路径并提交其他逆向、生图任务，原任务在后台继续。

## 独立选择模型

可在工作台「设置中心 → Codex CLI」检查并升级插件实际调用的本机 **Codex CLI**；仅更新桌面 App 不代表 CLI 已更新。旧 CLI 可能缺少 GPT-6.1 Sol、GPT-6 Astra、GPT-6 Sol 等模型。更新后重启本机服务并刷新列表，具体可用性以账号权限和验证结果为准。[官方更新说明](https://learn.chatgpt.com/docs/codex/cli) · [模型选择截图](docs/releases/v0.1.17.md)

连接设置中的「插件模型」从本机 Codex 获取图像输入模型列表，不写死模型名，也不修改 `~/.codex/config.toml`。首次使用或从旧版升级后，需选择模型并点击「验证并使用」。刷新列表不会自动调用推理；验证会通过同一个 Codex CLI 和登录状态发送一次简短请求，消耗少量模型额度，不发送项目图片。成功后保存到已忽略的 `.local/config/model-settings.json`，逆向和生图均显式使用已保存的模型及推理强度。

「推理强度」按所选模型动态显示支持的档位，并标注推荐值。切换模型时选中推荐档位；修改模型或强度后点击「验证并使用」才生效，验证失败保留原有效配置。当前使用区域显示已保存档位，刷新列表保留仍受支持的未提交选择；运行任务或验证期间不能切换。旧配置继续沿用已保存的强度；旧 CLI 未提供可选档位时仅提供其默认值，不猜测其他档位。新逆向及生图记录保存当次强度，旧记录不补写。这里控制的是 Codex 推理强度，不是生图画质等级。

模型目录可能包含缓存项，所以目录中的「待验证」不代表账号已经有调用权限。验证失败时保留原有选择，明确拒绝访问的模型标记为不可用；网络或额度问题不等同于模型权限问题。账号、登录状态或提供方变化后需重新验证。验证不会写入项目历史，已有提示词和图片保持原样；运行中的任务禁止切换模型。

验证成功表示当前请求可以完成推理，不保证内置生图工具可用或还有生图额度。生图仍单独检查提供方能力，并以真实工具结果为准。模型目录和请求协议参考 [OpenAI Docs](https://learn.chatgpt.com/docs/app-server)；[官方说明](https://developers.openai.com/siwc/token-sharing-open-source/codex-app-server)也提示目录不等于权限验证。

## 会话与执行记录

逆向、生图和模型验证默认使用 Codex 临时会话，避免后台任务堆积在 Codex 聊天历史中。Reframe 的项目、提示词和生成图片仍照常保存；临时会话结束后不能从 Codex 历史恢复，服务中断仍按原有规则将任务标记为失败。

排障时可在任务结束后运行 `npm stop`，再用 `ALCHEMY_PERSIST_CODEX_SESSIONS=1 npm start` 临时保留逆向与生图的执行会话；模型验证始终不保留。此开关不写入配置，下次普通启动恢复默认（若在 shell 中 export 过，先取消该环境变量）。已有 Codex 会话不会自动清理，需按 Reframe 记录中的 thread ID 单独归档。

## 任务指令

提取风格、完整复刻、主体重演和多图重演共用「任务指令」输入框，按路径预填默认要求，也可自行编辑。切换路径或提示词版本时各自保留草稿，已提交指令随对应版本保存；旧版记录继续恢复原指令。明确要求优先于路径默认分工，修改后需重新逆向才影响提示词。

完整复刻可补充需要保留、调整或排除的内容；仅提取通用风格也会使用当前指令。单图路径可清空指令使用默认分析，双图与多图仍需填写指令。

四条路径在人物适用时，要求中英文提示词各保留独立的「人物神态与微动作」段落：从可见的视线、眉眼与唇角变化，展开到头颈肩偏转、手指接触及动作牵动的衣褶和遮挡。完整复刻采用参考图细节；主体/多图重演按模板角色迁移神态与动作；双图提取风格默认保留主体图的表现，只转换画法。仅提取通用风格时写人物适用条件与表现机制，不锁定参考人物。任务指令可覆盖默认来源；目标无人时省略人物段；局部遮挡或低清时保留仍可辨的面部线索，只省略不可辨部位，不补造隐藏细节。更新后需重新逆向才会应用这些要求，历史提示词保持原样；实际复刻效果仍需对照生成结果验证。

四条路径还要求中英文正文单列「整体情绪与氛围」：描述人物或物体与整幅画面共同传达的主要感受、表达强弱及有依据的情绪反差，并写清构图、留白、光色、摆放和画法如何形成这些感受。静物与无人画面同样输出；平实画面保留中性或克制的表达，不强加故事。复刻/重演依据参考模板，通用风格抽取可迁移机制；仅换画法时保留主体内容和结构，只迁移兼容的氛围。用户可在任务指令中指定情绪目标，更新要求仍需重新逆向才生效。

## 提取风格

1. 从网页选择风格参考图，或打开历史记录，选择「提取风格」。
2. **图 1：你的主体原图**。上传 PNG、JPEG 或 WebP，默认保留主体身份、内容、姿态、表情、服饰、构图与背景结构。
3. **图 2：风格参考**。自动带入网页所选原图，仅提供配色、光影、笔触、边缘、媒介及材质表现。
4. **输入 3：任务指令**。已填好上述分工，可按自己的意图编辑；不会带入主体重演的旧指令。
5. 点击「生成风格转换提示词」。Codex 实际分析两张图，输出中英文专属提示词，不保留 `[SUBJECT]` 占位符。以后出图时，按 **图 1 主体 → 图 2 风格参考** 的顺序附图。

无需指定主体时，点击「仅提取通用风格」，只分析图 2 并生成带 `[SUBJECT]` 的可迁移配方；该操作不提交已上传的主体图，但会提交当前任务指令。双图转换任务会保存两张图和实际指令，可从历史恢复后更换主体继续使用。仅提取风格默认保留图 1 的结构；主体重演则默认采用图 2 的构图与姿态。

## 主体重演

1. 选择「主体重演」，从网页选一张参考图；也可打开当前或历史记录的原图，无需先完成一次逆向。
2. **图 1：主体图**。上传 PNG、JPEG 或 WebP，提供人物的身份特征或物体的辨识特征；界面显示实际预览。支持更换主体图。
3. **图 2：原始参考模板**。自动带入所选原图，默认提供风格、构图、内容关系、姿态、表情、光影、笔触和材质参考。
4. **输入 3：任务指令**。默认填好「以图 1 为主体，以图 2 为风格参考模板，生成基于图 1 的风格转换与主体重演提示词。」可直接使用，也可按意图改写，例如「保留图 1 的姿势，只迁移图 2 的配色与笔触」。Codex 按编辑后的指令决定保留与迁移内容，不强制套用默认模板分工，也不会自动带入旧逆向结果。
5. 点击「生成主体重演提示词」。输出中英文版本，明确两张图的职责。以后使用此 Prompt 出图时，按 **图 1 主体 → 图 2 模板** 的顺序附图。

逆向完成后可单独点击「用 Codex 生成图片」。主体身份随模板的新姿态和视角重新表现；模板类别不适配、关键细节不可见等情况在结果中说明，不能保证精确身份或像素一致。主体图原有的姿势和背景不会默认锁定。

网页悬浮图标仅收集参考图；打开对应项目并选择「主体重演」后，任务指令已预填，上传主体图即可提交。指令可编辑，清空时需重新填写。切换模式时保留当前表单输入；轻量两端未提交草稿保存在当前浏览器会话，进入工作台时随当前项目与版本接续。已提交的重演记录保存两张图与任务指令，可从历史恢复后继续编辑或更换主体再次运行。旧版重演记录沿用其当时提交的 Prompt，作为可编辑的任务输入。打开项目会切换当前参考模板，旧结果不被重写。

关闭浮层或弹窗不影响任务。停止 bridge 或关机将中止当前任务；重启后保留已完成记录，并将中断任务标记为失败。

画布图片不加衬底色块，完整显示原比例，切换横竖图不会改变展示区高度。图条切换参考与主体，替换、互换和移除统一放在图条下方工具栏，放大入口位于实际图片右下角。轻量两端保留紧凑画布与图条，多图编排在工作台完成。

准备画面（多图模式为组合画面）中的图片预览可左转或右转 90°，点击「应用旋转」后实际图片会用于后续逆向与生图；关闭未应用的预览不改变输入。旋转主体沿用当前草稿规则，多图主体旋转后须重新逆向。旋转参考图会按新图片创建或复用项目，保留当前模式的主体编排与任务指令，并进入待逆向状态。历史输入与生成结果不改写；项目列表、任务列表、生成结果和对照预览不提供旋转操作。

工作台的参考图与生成结果大图预览支持滚轮缩放、拖拽平移、双击放大/还原，以及底部加减与适应窗口按钮。聚焦图片后可用 `+` / `-` 缩放、方向键平移、`0` 还原，`Escape` 关闭；缩放范围为适应窗口大小的 1–8 倍。

## 图片角色互换

工作台与轻量两端均从图条下方工具栏互换主体与参考图；工作台「多图重演」先在图条选中主体，再点击互换图标。其余主体的顺序和分工不变，换入的主体恢复为自动用途并清空保留特征。

互换保留当前任务指令，按新的参考图创建或复用项目，并进入待逆向状态；旧提示词和生图记录不被覆盖。图片读取中或任务提交中不能互换，失败时保留原输入。超出主体大小限制的参考图会先尝试压缩，成功后才完成交换。

## 多图重演

在工作台选择「多图重演」，从图条加号批量添加 2–6 张主体图。点击缩略图选择主体，在图条下方工具栏替换、删除或打开主体设置，调整顺序、用途与保留特征；任务指令填写这些主体如何融合到同一画面。模板放在最后发送，主体图按界面顺序编号。

点击「逆向提示词」获得中英文提示词，再生成图片。改变主体、顺序、用途、特征或任务指令后，需要重新逆向。参考模板更换后按图片内容打开对应项目，保留当前主体编排。工作台生图前隐藏结果抽屉，提交后展开；生成后可查看结果、调整比例、编辑提示词与历史对照；历史原图来自当次生成的不可变快照。

上传格式为 PNG、JPEG、WebP，原文件最多 20 MB；主体压缩到每张 2 MB、参考图 4 MB 内。主体与模板保存在本机共享图片库；关闭界面不会中断已提交任务。未提交的主体和职责在当前界面中保留，工作台草稿交接上限为 8 MB，超限会明确提示。

## 工作台主操作

工作台采用画布与图条布局。图片展示区和图条高度由窗口决定，横图、竖图切换保持位置稳定；图片完整适应展示区。图条下方的悬浮工具栏集中四种逆向模式、替换、互换、移除、主体设置、提示词版本和面板开合，各路径与版本保留独立状态。画布和图条支持拖入图片，图片放大预览保留旋转、缩放与平移。

任务指令贴近底部，右下角小按钮生成或更新提示词，运行时可取消。没有提示词时隐藏面板；生成成功后自动展开，已有结果可从工具栏打开。展开时预留面板空间，工具栏保持可见，图片操作暂时禁用。面板提供中英文、复制、Markdown 导出、编辑、排除项，以及目标尺寸与生图按钮。修改任务指令或多图编排后须先更新提示词；已有主体时仍可点击「仅提取风格」只使用参考图。

面板打开时上滑 300ms；横条拖动直接跟手，向上越界增加阻力。下拉超过 60px 或有效轻甩关闭，否则约 420ms 弹簧回到打开位置。横条按钮、工具栏按钮、Escape 和向下方向键提供等效收起操作，焦点回到开关。拖拽取消回到打开状态；键盘和减少动态效果即时响应，关闭面板不丢弃提示词草稿或已提交任务。

## 编辑逆向提示词

轻量两端提供提示词阅读、语言切换与复制，点击「完整编辑」进入工作台；完整分析保留在工作台的 Markdown 导出中。

工作台四条路径的结果区都可点击铅笔图标「编辑提示词」，分别修改中文、English 与排除项；中英文不会自动翻译，排除项可以清空。点击「保存修改」后持久保存到当前提示词版本，后续复制、Markdown 导出和生图使用修改后的内容，无需重新逆向。已经提交的生图保留当时的提示词和排除项，其他提示词版本不受影响。

编辑中可以复制当前文字；生图与导出需先保存或取消编辑。草稿在当前界面切换路径、语言和版本时保留，关闭面板前请保存。取消编辑回到已保存内容。

## 一键生成图片

工作台生图前可选择图片比例：自动、1:1、3:2、2:3、4:3、3:4、16:9、9:16，或自定义宽高。自定义输入表示比例而非像素，宽高各为 1–10000 的整数，比例范围为 1:20–20:1。选择通过提示词追加到本次生图，不能保证严格执行，也不对结果裁剪或拉伸；结果仅显示图片的像素尺寸与实际宽高比。重新打开当前提示词版本时沿用最近一次生图的比例，未提交的选择不持久保存。轻量两端快捷生图沿用该版本最近一次生图比例，无历史时使用自动；需要指定尺寸时进入工作台。

1. 完成双图「提取风格」、「主体重演」或单图「完整复刻」，也可打开已有完成记录。
2. 选择结果区的中文或 English，然后点击「用 Codex 生成图片」。服务发送该记录对应语言的提示词与排除项；观察边界保留在分析结果中。
3. 「完整复刻」使用纯文生图，不附参考图；参考图只在逆向提示词阶段使用。「提取风格」的专属风格转换和「主体重演」按当前表单显示的主体图、该提示词版本的参考图的顺序附图。换主体后可直接使用已有提示词生图，无需重新逆向；新图读取中或读取失败时不能生图。
4. 完成后直接预览；macOS 可点击「打开图片」用默认看图软件打开，或点击「在文件夹中显示」在 Finder 中选中当前图片。点击「复制图片路径」获取当前图片在本机的绝对路径，不再另存一份；点击「再生成一张」保留前一次输出，并可在生成记录中切换。关闭面板后任务继续运行，重新打开该历史记录可恢复结果。

打开与定位操作适用于工作台、工具栏弹窗和网页浮层，始终使用当前选中的生成记录。其他系统暂不支持直接打开，可继续复制路径。需要更新并重启本机服务、重新加载扩展；文件已被移走或损坏时会显示错误。

每次生图固定保存当次主体图的引用，后续换图不会改动旧结果、旧生图输入或逆向时的主体原图。重新打开提示词记录时优先恢复最近一次生图的主体。只有上传而尚未提交的图片仍是界面草稿。编辑任务指令后，需重新生成提示词才会影响生图使用的文字。

通用风格配方尚未指定主体，需先上传主体图并生成专属提示词，不能直接将 `[SUBJECT]` 发去生图。双图路径缺少必要图片时会明确报错，不静默降级成纯文字生成；逆向原主体图缺失时可上传新主体继续生图。完整复刻使用已有提示词生图时不依赖原图文件。

生图通过本机 `codex app-server` 发起独立任务，显式调用 `imagegen` 技能及内置 `image_gen`；不使用 `scripts/image_gen.py` 或模型 API Key。沿用 Codex 登录及额度，需要该模型提供方支持内置生图。不可用、额度耗尽或生成失败时显示错误，不切换到其他生图接口。生图可能需要几分钟；取消停止本机等待与后续处理，已经发起的模型调用可能仍消耗额度。

桥接程序只接受 App Server 的 `imageGeneration` 完成事件，不把聊天文字或路径描述视作生成结果。输出从 Codex `generated_images/` 目录读取或从工具返回的图片字节读取，再存入 `.local/`，不覆盖输入图片、不提交 Git。生图图片单张最多 20 MB，仅按需发送到面板，不写入扩展 storage。

### 任务完成提醒

逆向或生图结束后，任务中心保留未查看标记，扩展图标显示数量。正在查看对应结果时直接更新；在 Reframe 内查看别处时轻提示一次，离开 Reframe 时发送静默桌面通知。点击单条提醒打开对应提示词或生图版本，多条提醒进入任务中心。提醒优先在当前工作台内跳转；从网页、弹窗或桌面通知进入时复用已打开的工作台并激活所在窗口，仅没有工作台时新建标签。页内跳转不重载工作台；关闭提醒不会清除未读。已读判断以实际结果正文/图片/错误文本进入可见区域为准，滚动容器外或只露出标题不会清除；已读或隐藏后的轻提示随同步移除。

「设置中心 → 任务提醒」中的声音默认关闭，开启后可选择轻柔/清铃、音量并试听。开关本身不发声。接连完成的任务合并提醒，不循环、不催看；取消不提醒，首次启用不补发旧历史。隐藏项目不主动弹出或发声；未读数量遵循「包含隐藏项目」开关。

新增 `notifications` 权限用于桌面提醒，`offscreen` 仅在用户开启声音或试听时播放短提示音，`alarms` 用于后台恢复同步。提醒状态、已读记录和声音偏好保存在扩展本地存储；桌面通知不包含图片、提示词、项目名称或文件路径。系统通知被关闭时，界面与未读标记仍可用。浏览器需保持运行且本机服务可连接；休眠、断线或后台恢复时可能延迟，恢复后先核对最新状态再合并派发；无法连接时保留待提醒记录，不直接发送缓存通知。

更新后需在任务结束时重启本机服务并重新加载扩展，使后台任务接口与新增权限生效。真实桌面通知和声音仍需分别在 Chrome / Codex 内置浏览器验收；界面预览不播放声音。

## 本机 Codex 与技能

- 不集成模型 API、不保存 API Key；通过 `codex app-server` 的 stdio JSON-RPC 调用本机 Codex，沿用其登录，使用插件单独选择并验证的模型。本机 Agent 仍可能使用云端模型，并非离线推理。
- 显式发送 `localImage` 和 `skill` 输入。项目真实技能名为 `alchemy`，随仓库提供于 `.agents/skills/alchemy/SKILL.md`；QC-Reframe 是扩展产品名。
- 逆向先定位整图，再裁切放大关键特征、材质、光影与边缘，回看整图后编写提示词。局部工具仅处理本次输入，直接返回图像；不会修改原件或保存裁切文件。观察摘要的条数不限制细查范围，原图无法分辨的细节会列为限制。
- 图片检查进度区分整图查看、局部检查与失败，并显示实际输入图号。局部显示目标放大倍率，实际输出受尺寸上限约束；放大不增加原图细节。工具提供统一的图像展示示例，减少返回格式试错和重复读取。
- Agent 采用只读 sandbox，不自动批准交互式工具操作。逆向输出使用 JSON Schema 约束和本机校验；生图使用内置工具保存并由 bridge 复制结果。
- 每次逆向创建独立 Codex 临时会话，不接管当前桌面聊天；仅显式开启上述排障开关时保留执行会话。

可自定义本地路径：

```bash
CODEX_BIN=/absolute/path/to/codex \
ALCHEMY_SKILL_PATH=/absolute/path/to/alchemy/SKILL.md \
IMAGEGEN_SKILL_PATH=/absolute/path/to/imagegen/SKILL.md \
npm run setup
```

随后运行 `npm start`，路径会从 `.local/config/runtime.json` 恢复；环境变量可覆盖保存值。

需保留技能的 `references/` 等伴随文件。启动前可用 `codex --version`、`codex login status` 检查 CLI；CLI 不在 PATH 时设置 `CODEX_BIN`。

imagegen 默认位于 `$CODEX_HOME/skills/.system/imagegen/SKILL.md`（未设置 `CODEX_HOME` 时使用 `~/.codex`）。

## 图片与数据

普通安装的运行数据统一放在 `browser-extension/.local/`（可用 `ALCHEMY_DATA_DIR` 指定整个数据目录），按用途收纳：

```text
.local/
├── config/     # 配对码、模型设置、CLI 与技能路径
├── records/    # 项目、提示词、任务与生成记录
├── images/     # 按内容去重的图片
├── logs/       # 本机服务日志
└── runtime/    # 启动锁等临时状态
```

日常使用不需要手动管理这些文件。服务停止后，备份整个 `.local/` 即可保留配对、配置与项目；恢复时沿用完整目录，并使用支持该布局的新版服务。自动生成的日志在下次启动时若达到 5 MB，会轮替为 `bridge.log.1`，只保留当前日志和上一份。

旧安装在服务重启时自动将根部的配对码、配置、项目/任务 JSON 和服务日志归入相应目录；图片共享路径保持不变。迁移可在中断后继续，同名文件内容冲突时保留双方并停止迁移。旧服务运行期间，查看状态和停止服务仍能读取旧配对配置，不会提前搬动正在使用的数据。开发测试资料、手动导出及无法确认归属的旧文件保留原位，不属于普通安装自动产生的目录布局。

参考图、主体图和生成结果统一存入 `.local/images/`，按文件内容 SHA256 去重。相同图片在多个项目、任务和生成记录中只保存一份；主体快照通过固定引用保留，后续换图不会改变历史输入。重新压缩、裁剪或转换格式后的文件可能被识别为另一张图。

首次启动更新后的本机服务时，会自动迁移历史图片：先保存并校验共享文件、原子更新记录，再清理已迁移的旧副本。迁移中断可以重启继续；发现损坏的记录时保留图片，暂停自动清理。生成结果的本机路径会改变，请从结果面板重新复制；此存储格式需要使用更新后的服务。迁移不整理仓库根目录 `output/`、用户原图或 Codex 自己的输出目录，也不需要重新配对。

- 悬浮检测在网页内执行，**点击前不上传图片**。只发送选择的图片、模式、任务指令和去除查询参数的来源 URL；双图和多图路径还发送用户上传的主体图及其分工。网页正文、cookie、登录数据不会交给 bridge。
- 优先读取当前图片资源，不携带网页 cookie；支持 `<img>` / `<picture>` 当前资源和单层 CSS 背景图。最长边限制为 2560 像素，优先 PNG；较大图转 JPEG。
- 原图无法读取时，悬浮入口尝试截取所选图片的可见区域，标记「屏幕截取」。不会将整个网页截图交给模型。图片需完整可见；页面变动或切换标签时拒绝截取。
- 主体上传原文件最大 20 MB，浏览器实际解码后将最长边限制为 2560 像素，保存体积最多 2 MB；参考图保存最多 4 MB，避免双图超过扩展 storage 配额。任务指令最多 20000 字符。点击生成前，主体图只在表单中读取与预览。
- 跨域 iframe、canvas、浏览器内部页、Chrome Web Store 页面，以及被遮挡或未加载的图片不保证支持。右键入口下载失败时需改用悬浮入口。
- 为支持任意网站与截图，扩展请求 `<all_urls>`；不会自动批量发送网页图片。
- bridge 仅监听 `127.0.0.1:43187`，请求需配对令牌，并校验 Host 和浏览器 Origin。令牌仅用于本机配对。
- 令牌、选中图片、历史结果位于 `.local/`（已忽略提交）；扩展 storage 保留当前图片、连接设置、任务提醒状态与声音偏好。模型处理遵循你的 Codex 账户配置。
- 多项逆向、生图可同时执行；进度、取消和结果各自独立，在「项目记录」进入相应项目查看。同一条提示词已有生图执行时需等待完成或取消，其他提示词版本仍可生图。任务执行期间不能切换模型，模型验证期间需等待验证结束再提交新任务。
- 历史任务接口展示所有活跃任务和最近 30 个已结束的逆向版本（按最近逆向或生图时间排列），项目记录保留全部路径与版本。停止服务后可手动删除 `.local/` 清空记录；删除 token 后需重新配对。

## 开发与验证

界面只常驻显示操作标签、必要状态与限制。动效说明、通用风格提示词用法可悬停预览，也可点击或用键盘展开；安装路径、检查时间和升级命令收纳在设置的「安装与检查详情」。轻量面板已连接时收起配对指引，未连接时直接展示。未使用路径不重复显示待生成状态，空排除项仅在编辑时出现；错误、任务进度、费用提示和删除后果仍直接展示。

为兼容已有安装，内部 `alchemy:*` 消息、`qc-alchemy` 服务标识、`ALCHEMY_*` 环境变量和 `.local/` 数据位置沿用；独立的 `alchemy` 图片逆向技能名也不变。更新原安装目录后，在任务结束时重启本机服务，由服务自动迁移数据，再重新加载扩展并刷新网页。

品牌标识采用 Raft 的亮黄 `#ffd440`、墨黑 `#141111`、青色 `#27ccf3` 与粉色 `#fe7da8`，几何 R 标识保留品牌原有的圆角与右下硬阴影；界面内容使用更轻的色面与留白。当前品牌源图为 `assets/brand/reframe.svg`。界面内嵌该 SVG，避免扩展资源地址在网页浮层中不可用；`npm run icons` 从同一源图生成 `public/icon/` 中的 16/32/48/96/128 px 图标。`build` 与 `zip` 会先更新图标。

Git 保存 `browser-extension/`、根目录 README、贡献指南与忽略规则。本地 `.local/`（配对令牌、Prompt JSON、参考图、截图）、下载/实验目录、依赖与构建产物不提交，也不会被删除；必要的品牌 SVG/PNG 和项目配置 JSON 正常提交。`alchemy` 的发布副本位于本目录 `.agents/skills/alchemy/`，包含运行所需参考文档；不包含作者的历史案例、Prompt JSON、来源索引或图片。`ALCHEMY_SKILL_PATH` 可指定其他完整安装。`imagegen` 使用新用户自己 Codex 中的技能，不随本仓库分发。

```bash
npm run dev       # WXT 开发模式
npm run compile   # TypeScript 检查
npm test          # 先 build；验证 bridge、任务状态与扩展兼容性
npm run build     # .output/chrome-mv3
npm run zip       # 扩展 ZIP，不包含本机 bridge / skill
npm run preview   # 弹窗视觉预览，不调用 Codex
```

预览地址 `http://127.0.0.1:43188/?state=result`，也支持 `empty`、`running`、`failed`、`reenact`、`style-new`、`reenact-new`（尚未逆向的参考图）、`generation`、`generation-completed`（生图交互示例），均使用明确标记的示例数据。主体图上传和指令编辑使用真实表单；预览的提交按钮不调用 Codex。增加 `&reminder=toast&tasks=unread` 查看提醒及未读示例，`&reminderTask=image` 切换图片提醒，点击提醒在当前工作台内定位对应示例结果；`&case=任意新值` 重置该组未读示例，`popup.html?state=projects&reminder=unread&reminderTask=image&panelClip=1&case=clip` 验证裁剪和滚动已读（快捷界面组件 fixture，不代表真实 content 浮层）。`&notificationDenied=1` 模拟通知权限关闭；设置声音只修改预览偏好，不播放声音。预览不能替代真实扩展中的权限、声音、悬浮和跨域图片验收。 工作台提交边界可用 `?state=projects&generationStartDelay=4000&generationDelay=2000` 验证（主体重演路径为首次生成，提取风格为已有结果）；加 `generationStart=failed` 模拟提交失败，`motion=reduce` 检查静态反馈。提交延迟最多 60 秒，仅作用于示例，不调用模型。

`/content-preview` 用于网页内浮层验收，`?state=invalidated` 可模拟扩展失效提示；同样只使用示例数据。

画廊正式组件预览：`/workspace.html?state=works`，点击左侧「作品画廊」。加 `&count=1200` 验证分页与窗口化，`&count=0` 查看空态，`&galleryFail=once` 验证读取失败重试，`&galleryImageFail=1` 模拟原图读取失败，`&galleryDelay=1000` 检查筛选请求交错。仅使用公开示例与合成素材，不读写真实项目或调用模型；重复素材的压力测试不代表真实图库内存基准。

`/collection-preview` 用于连续收集入口与保存反馈的示例验收，不执行真实保存；项目库筛选可在 `/?state=library` 的示例项目中检查。

`/panel-preview?state=multi-new`（空主体）或 `?state=multi`（已有主体）可通过「打开示例面板」检查多图重演的真实 Shadow DOM 浮层。`/panel-preview` 将当前构建放在示例 iframe 中，避免浏览器已安装的旧扩展遮住待验收浮层；只用于 UI 验证，不改变扩展在真实网页上的 iframe 支持范围。

人工验收：重启 bridge、重新加载扩展并刷新网页 → 配对连接 → 连续点击不同图片的 Reframe 图标，确认保存反馈且当前项目不变 → 重复加入、断开服务后重试 → 在「待逆向」筛选中找到图片 → 用右键逆向入口打开面板，确认对应参考图。按任务授权范围继续检查真实逆向、复制提示词、取消与浮层重开；示例预览不能证明真实保存与跨域捕获成功。
