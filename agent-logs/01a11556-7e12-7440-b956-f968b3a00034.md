### 规范怎样提炼

建议未来在 `browser-extension/docs/uiux/` 设置短入口，按以下四类组织；当前 AGENTS 的 UI 规则经 PM 迁移或链接后只保留必要入口，不复制两份长期正文。本轮不创建正式规则。

1. **设计基础**：颜色、文字层级、间距、圆角、图标、阴影、动效及合法变体。第一阶段继续以现有 CSS token 为唯一数值来源，提取清单和使用位置；确认需要复用的缺失语义才补 token。将来若需要设计工具交换，再一次性改为结构化 token 源生成 CSS，禁止 CSS/JSON 双向手填。
2. **布局与页面模式**：工作台、popup、网页浮层的容器和滚动所有权、双画布四轨、页头、共用操作栏、断点与浮层挂载边界。用关系表达：等宽、同基线、只挤压编辑区、contain；不要抄写一张截图的全套坐标。
3. **组件使用契约**：对 SelectField、ImagePreview、QuickWorkspace、TaskInstruction、dialog helper 等列出入口、适用场景、允许变体、状态、不能复制的行为。先给现有组件建目录；只有确认重复且语义相同再抽取，不立即引入大型组件平台。
4. **体验状态与交互**：空/加载/失败/禁用/完成、长文本、输入未保存、键盘/Escape/焦点恢复、减少动态效果、异步进度位置与操作可达性。复用领域层判断，UI 规范不复制业务状态机。

每条规则使用稳定 ID，连接「意图、权威来源、作用表面、源码所有者、场景、断言、例外、验证级别」。结构化登记只维护映射和可测要求，设计数值引用 token，不重复抄值。文档展示可从登记生成；运行时断言必须独立测量，不能读同一 CSS 值就宣告正确。

### 工具提案（命令名仅为建议，尚未实现）

统一收在 `agent-tool`，可采用一个薄入口 `node agent-tool/ui.mjs <子命令>`，不要为每条规则创建孤立脚本。

| 子命令 | 用途 | 输出 |
| --- | --- | --- |
| `context --files …` | 改动前找到对应规则、组件、token、场景和影响表面 | 短 Markdown/JSON；未知影响回退完整 UI 核验，不能静默跳过 |
| `check --changed` | 静态检查 CSS 装载边界、未定义变量、新增品牌色绕过 token、已登记禁止样式、场景/规则链接失效 | 规则 ID、文件行号、实际声明、建议复用入口 |
| `verify --scenario …` | 统一运行已有浏览器行为脚本，追加实际 DOM 几何断言、少量视觉回归 | 结果摘要、场景/环境、几何值、截图及失败 trace |
| `inspect --scenario … --target …` | 定位一次失败，复用同一场景与采样器 | 目标与父级 rect、关键 computed styles、滚动/裁剪祖先、相关 token、截图标注、源码候选位置 |

第一阶段只做 `check` 与 `verify` 的小范围闭环，`inspect` 先作为失败时自动生成报告，之后再扩成交互式命令；`context` 可先用静态索引实现。AST/parser 检查结构，正则只做盘点；不要承诺静态工具可靠判断“重复组件”或所有设计好坏。

静态规则先分 error/warn/review：明确 import 越界、未定义 token 等可阻断；历史裸值和疑似重复先警告；视觉方向和文案层级仍需设计复核。历史例外限定到规则、组件/声明、原因和复查条件，禁止全目录忽略；对新改动逐步收紧，不让全部历史债务阻塞新功能。

报告建议稳定字段：`schemaVersion, ruleId, severity, surface, scenario, viewport, sourceRevision, sourceDirty, sourceFiles, target, expected, actual, evidence, reproduction`；环境附浏览器/字体/DPR/语言/预览壳和构建指纹。期望、实际与疑似原因分别展示。computed style 本身不能证明某行源码是根因；MVP 给相关源文件候选，精确级联来源需要专用浏览器适配，不能伪造归因。输出先给首要失败摘要，再链接完整报告，适合 agent 上下文。

### 第一批验收场景与规则

- 双画布：抽屉展开后两侧等宽、标签/画布/图条/操作区基线一致；提示词开合和长文本不单侧挤偏。基于最终 rect 比较，约 1 CSS px 的容差仅为待校准建议，不直接当正式标准。
- 轻量表面：画布180px、图条36px，主操作不被裁切；视口与内容极端情况分别覆盖。
- 图片预览：横/竖/方图、加载失败，按钮锚定实际 contain 图像边缘；允许的遮叠单列，不把所有矩形相交视为错误。
- 样式隔离：共享组件不得直接加载 CSS；网页宿主的强样式不污染插件，插件样式不污染宿主。closed ShadowRoot 无访问能力必须标记未覆盖，不能当 PASS。
- 交互：窄屏关闭侧 inert、操作可达、Escape/焦点恢复、错误与取消仍可用；遵从项目当前聚焦视觉决策，不擅自更改它。

场景使用合成图片/文字与隔离存储，沿用现有 fixture；固定时间、浏览器、字体、DPR和窗口，等待字体/图片/布局就绪。静态截图关闭非必要动效；另设少量动效交互验收，不能由静态图声称动效正确。预览与真实扩展分开基线；closed Shadow DOM 普通 locator 不支持，先自动化工作台/popup，浮层记录可用交互/截图及人工复核边界，不为诊断改生产 Shadow 模式。

工具自身验收用隔离 fixture 注入已知失败：新增裸品牌色、共享组件 CSS 越界、单侧多8px padding、长文本撑开、预览按钮锚到留白；各自应报正确 ruleId 与实际测量。合规变体不误报；已有失败不能用一键刷新基线消除。报告成功也需写清已覆盖/未覆盖、预览/实机、源码/构建是否一致。

### 人类调整设计时如何同步

一次设计变更对应同一改动集：记录设计意图与受影响规则 → 修改唯一 token/组件/布局来源 → 修改确实变化的契约与场景 → 生成索引/文档并检查过期 → 查看新旧截图与影响范围 → 复核后更新指定基线。工具可以自动查依赖、生成清单与过期提示，但不能自动理解人类意图，不能检测到视觉变化就自动覆盖旧期望。

token 改动扩大到所有使用者，公共布局/组件改动扩大到所有关联表面；不能只测新功能页面。应检查规则、场景、组件映射和生成文档完整性，不用“必须修改每份文档”形式检查替代真实影响分析。每项规则记录适用面，避免把 popup 的固定高度套到工作台。

### 推荐落地顺序与分工

1. **盘点并裁定**：UIUX 整理已确认规范、合法变体、静态分歧、组件与场景地图；PM 维护正式文档入口，监工复核。验收是新 agent 能按功能定位权威来源，分歧没有被直接固化。
2. **最小闭环**：架构/工具执行者在迁移后的 preview 上加统一 runner、5条关键契约与失败报告；UIUX 给几何验收和设计复核。验收以故障注入可抓到、合规变体不误报、复现命令可重复为准。
3. **持续演进**：扩到有限视觉基线、变更影响映射、组件示例页与同步检查；必要时接 CI。先证明本地可重复，再扩大门禁，不以一次性全面 token 化为前置条件。

不要求先引入 Storybook、全新 token 构建链或视觉 SaaS。若后续组件数量/设计工具协作确实需要，再比较迁移收益。当前最大收益来自复用现有预览并把明确规则变成测量。

### 外部技术核对

研究问题限于截图/诊断能力及 token 交换格式，2轮官方来源检索，主线直接完成。使用 modern-web-guidance 的 search/retrieve css-layout，原则用于关系布局/溢出诊断；本轮不据该指南升级浏览器特性或改实现。

- [Playwright visual comparisons](https://playwright.dev/docs/test-snapshots)：可做截图比较，但环境差异影响结果，需固定环境并复核基线。
- [Playwright Trace Viewer](https://playwright.dev/docs/trace-viewer)：失败时保留操作、DOM与截图证据，可作为 verify 的诊断出口。
- [Playwright Shadow DOM 限制](https://playwright.dev/docs/locators#locate-in-shadow-dom)：closed roots 不受普通 locator 支持；本项目必须显式报告这项覆盖边界。
- [DTCG 2025.10 format](https://www.w3.org/community/reports/design-tokens/CG-FINAL-format-20251028/)：供未来设计工具间交换评估，是社区规范，不是本轮必须迁移的前置条件。

### 实施结果

- 新增 `agent-tool/ui.mjs` 统一 `context / check / verify / inspect / sync` 入口，模块位于 `agent-tool/ui/`。按脚本定位依赖与资源，使用扩展同一依赖树；无独立 package，无产品组件/样式修改。

- 静态检查使用 TS/PostCSS AST：样式 import 越界、变量未定义/无 fallback、新增行等价裸品牌色；历史裸值警告。删除 token 会检查未改动消费者；未知依赖 context 回退全场景。明确声明运行时级联/CSS-in-JS未完整求值。
