### 实现与关键决策

- **先修升级收尾与首次启动。** `bridge/cli.mjs` / `server.mjs` 正确等待异步模型重置和接口复检；区分升级失败与“CLI 已升级，复检未完成”，异常不残留 running。显式重新检测清除旧终态，后台检查保留历史；并发 check 不清除新运行操作。`scripts/manage.mjs` 的 setup 对缺 CLI、未登录、旧 app-server 提供维护模式继续构建；Node/Alchemy 检查与独立 doctor 仍严格。
- **服务在线不等于模型就绪。** health 非阻塞返回 serviceReady/skillReady、缓存 CLI 摘要；日常使用也启动每日版本检查。App 显示“本机服务已连接”，缺技能不再阻止进入 CLI 维护。版本无法检测/网络失败不显示最新；App/custom 的 npm 稳定版只标“版本参考”，不推断 App 更新资格或自动覆盖。
- **按实际接口判断。** 新 `bridge/compatibility.mjs` 本机只读导出实验 schema，按模型/逆向/生图/会话独立判定 supported/unsupported/unknown；8 秒命令超时、16 MiB 文件边界、临时目录 finally 清理，缓存随实际路径/文件信息/npm 包版本改变失效。未知放行，明确缺能力才拒绝对应请求，并在写记录前返回。旧版嵌入式会话正文不要求分页接口；实际分页失败由 RPC 分类恢复，避免扩大禁用。
- **错误有去处。** 新 `bridge/errors.mjs` 区分协议缺失与账号/模型问题，服务保留 recovery/code；新 `lib/codex-status.ts` 与 `RecoveryAction.tsx` 兼容历史文本错误。App、QuickWorkspace、CanvasWorkspace、GenerationPanel、SessionPicker、ModelSettings、SettingsCenter 复用现有按钮与设置分类，工作台 handoff 保留草稿并携带目标分类。
- **恢复保留原任务。** 会话弹窗在设置叠开时保持挂载，返回后未确认选择、搜索及焦点保留；不自动重试任务、不自动调用模型。缺 CLI 主操作为安装说明，安装后可重新检测；升级后模型验证范围明确为文字请求，图片/生图仍受接口、账号和权限限制。模型页不提供跳回自身的恢复按钮。
- README、INSTALL_WITH_CODEX 与 unreleased 统一当前发布入口 v0.3.3，明确本轮仍为未发布改动，区分 CLI 更新、源码/服务更新、扩展重载和网页刷新。无 CSS/layout 改动，无新增权限。
